# SIMPL-10171: Configure Onboarding Procedure Templates

**L1 requirement (high-level requirement)**

**Trace:** [BP02A](../../README.md) › [SIMPL-18783](../README.md) (L0) › **SIMPL-10171** (L1)

## What this item is

This L1 requirement lets the Governance Authority define what a new participant must provide to be onboarded. Its title matches step BP02A.02 "Configure onboarding procedure templates". Neither the item nor the public page links requirement and step explicitly. On the public requirements site it is high-level requirement 2A.1.

## Text

Simpl shall provide UI and APIs that support the creation and management of onboarding procedure templates to define the information a dataspace participant must provide for onboarding. Each template can also be enriched with validation rules to facilitate the review of participant onboarding requests.
