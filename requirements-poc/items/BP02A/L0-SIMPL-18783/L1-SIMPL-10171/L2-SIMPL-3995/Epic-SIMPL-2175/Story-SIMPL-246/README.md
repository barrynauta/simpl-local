# SIMPL-246: [UI] Onboarding administration dashboard - access granted

**User story (implementable work)** · Development: **Developed**

**Trace:** [BP02A](../../../../../README.md) › [SIMPL-18783](../../../../README.md) (L0) › [SIMPL-10171](../../../README.md) (L1) › [SIMPL-3995](../../README.md) (L2) › [SIMPL-2175](../README.md) (Epic) › **SIMPL-246** (User story)

## Text

**As a** dataspace governance authority user with the T2IAA_M role\
**I want to** access the administration dashboard of the Public Dataspace Onboarding Site through keycloak configured into my agent (Tier 1)\
**So that** I access the administration panel

**Linked Sovereign X US ID:** ARU_US_001

**Acceptance Criteria:**

1. **A dataspace governance authority user accesses the login page for the public dataspace onboarding site by clicking on the Keycloak login button.**
1. **A dataspace governance authority user fills the login form composed of username and password.**
1. **A dataspace governance authority user, with the T2IAA_M role, enters into the administration panel of the public dataspace onboarding site. ^(1)^**

**^(1) As of 30/06/2025 The T2IAA_M role can access only the pages to manage onboarding procedures /onboarding/administration/management/onboarding-procedures^**
