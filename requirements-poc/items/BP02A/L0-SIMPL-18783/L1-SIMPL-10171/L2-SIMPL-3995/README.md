# SIMPL-3995: Define the onboarding process documentation

**L2 requirement (detailed requirement)** · Status **In Progress**

**Trace:** [BP02A](../../../README.md) › [SIMPL-18783](../../README.md) (L0) › [SIMPL-10171](../README.md) (L1) › **SIMPL-3995** (L2)

## Text

Simpl shall provide a UI and API where:

- the data space governance authority can define which resources/documentation an applicant data space participant can provide to start the onboarding.
- the data space governance authority can define which resources/documentation are mandatory to provide during the onboarding procedure
