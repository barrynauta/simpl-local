# SIMPL-10174: Define identity attributes for an Onboarding Procedure Template

**L2 requirement (detailed requirement)**

**Trace:** [BP02A](../../../README.md) › [SIMPL-18783](../../README.md) (L0) › [SIMPL-10171](../README.md) (L1) › **SIMPL-10174** (L2)

## Text

Simpl shall provide a UI and APIs to link identity attributes to an onboarding procedure template. Identity attributes associated with the template will be suggested to Governance Authority onboarding reviewers before the approval of the onboarding request and can also be used for automatic onboarding attribute selection.
