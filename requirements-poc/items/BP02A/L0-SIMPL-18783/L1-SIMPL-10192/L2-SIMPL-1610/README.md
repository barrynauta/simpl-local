# SIMPL-1610: Defining preconfigured attributes

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP02A](../../../README.md) › [SIMPL-18783](../../README.md) (L0) › [SIMPL-10192](../README.md) (L1) › **SIMPL-1610** (L2)

## Text

SIMPL shall provide a set of predefined attributes, to be used for describing the participant's type (app/infra/data provider or consumer).\
Granting an attribute identifies the participant agent inside the data space, allowing/restricting access to data space functionalities (searching in all catalogues, publishing app/infra/data catalogues, …)
