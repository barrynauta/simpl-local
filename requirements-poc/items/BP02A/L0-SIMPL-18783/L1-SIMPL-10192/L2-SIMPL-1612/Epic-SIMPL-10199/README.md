# SIMPL-10199: Managing identity attributes

**Epic (deliverable, testable feature)** · Status **In Preparation**

**Trace:** [BP02A](../../../../README.md) › [SIMPL-18783](../../../README.md) (L0) › [SIMPL-10192](../../README.md) (L1) › [SIMPL-1612](../README.md) (L2) › **SIMPL-10199** (Epic)

## Text

**As A**\
data space authority\
**I want**\
a UI and an API to create, list, modify, delete, enable and disable identity attributes\
**So that**\
I manage identity attributes

**Acceptance Criteria**\
This Epic will be considered as done once all the child US will be closed/marked as done.
