# SIMPL-1612: Tier 2 identity attributes configuration

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [BP02A](../../../README.md) › [SIMPL-18783](../../README.md) (L0) › [SIMPL-10192](../README.md) (L1) › **SIMPL-1612** (L2)

## Text

SIMPL shall provide a UI and API where:

- a data space authority end user, with appropriate roles, can view the list of available identity attributes
- a data space authority end user, with appropriate roles, can create a new identity attribute
- a data space authority end user, with appropriate roles, can modify an existing identity attribute
- a data space authority end user, with appropriate roles, can enable/disable an existing identity attribute
- a data space authority end user, with appropriate roles, can remove an existing unused identity attribute
- a data space authority end user, with appropriate roles, can enable an existing identity attribute to be assignable to Tier 1 roles. Assigned identity attributes will be included in the Tier 1 user credential that belongs to that role
- a data space authority end user, with appropriate roles, can mark identity attributes as public and federable
