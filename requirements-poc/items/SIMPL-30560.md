# SIMPL-30560: Participant executes workflow on saved distribution configuration

## What this item is

This L1 requirement covers running a data workflow with the distribution model and infrastructure target that were saved when the workflow was defined. By the public process pages it belongs to [SA01 Data orchestration used by a Participant](https://code.europa.eu/simpl/simpl-open/foundations/business-processes/-/blob/main/sa01-data-orchestration/README.md).

## Requirement

> Simpl-Open shall execute the workflow using the distribution model and infrastructure target saved during workflow definition.

Public pages: [1.6 in the business-processes repository](https://code.europa.eu/simpl/simpl-open/foundations/business-processes/-/blob/main/sa01-data-orchestration/sa16-participant-executes-workflow-saved-distribution-configuration.md) and on the [requirements site](https://simpl-programme.ec.europa.eu/book-page/16-participant-executes-workflow-saved-distribution-configuration).
