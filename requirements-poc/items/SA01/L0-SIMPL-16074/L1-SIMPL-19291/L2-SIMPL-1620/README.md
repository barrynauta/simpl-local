# SIMPL-1620: Participant tracks data lineage for processed datasets

**L2 requirement (detailed requirement)**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19291](../README.md) (L1) › **SIMPL-1620** (L2)

## Text

Simpl-Open shall support a *Participant* to automatically capture and document dataset lineage when a dataset is processed using Simpl-Open data orchestration and processing workflows, by recording standardised metadata about data sources, applied transformations, and resulting datasets, ensuring traceability and transparency of dataset derivation.
