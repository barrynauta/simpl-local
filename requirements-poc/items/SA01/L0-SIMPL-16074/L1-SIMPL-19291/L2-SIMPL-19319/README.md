# SIMPL-19319: Participant executes data orchestration workflows automatically based on events

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19291](../README.md) (L1) › **SIMPL-19319** (L2)

## Text

Simpl shall provide capabilities that enable a Participant to associate an already created data orchestration workflow to a resource description upon its creation and its automatic execution through an event-based triggering mechanism.\
At least the following triggering options shall be supported:

- During consumption of an input dataset

- Input dataset change
