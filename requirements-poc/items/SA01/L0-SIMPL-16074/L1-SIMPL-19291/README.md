# SIMPL-19291: Participant executes a data orchestration workflow

**L1 requirement (high-level requirement)**

**Trace:** [SA01](../../README.md) › [SIMPL-16074](../README.md) (L0) › **SIMPL-19291** (L1)

## Text

Simpl-Open shall support a *Participant* to start the execution of a data orchestration workflow by using the triggering mechanism configured during its creation.  Simpl-Open shall give feedback to the user about the success or failure of the execution.
