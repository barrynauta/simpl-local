# SIMPL-30527: Participant defines sub-service distribution model

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-30520](../README.md) (L1) › **SIMPL-30527** (L2)

## Text

Simpl-Open shall allow a *Participant* to define the sub-service distribution model, i.e., this model breaks a single service into tiny chunks (data partitioning) and processes those chunks across a specialized compute cluster (like Dask or Spark).
