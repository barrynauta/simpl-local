# SIMPL-30525: Participant defines service distribution model

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-30520](../README.md) (L1) › **SIMPL-30525** (L2)

## Text

Simpl-Open shall allow a *Participant* to define the service distribution model, i.e., this model breaks a workflow into its constituent services (e.g., Extract, then transform, then load).
