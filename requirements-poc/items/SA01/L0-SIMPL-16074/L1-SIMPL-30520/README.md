# SIMPL-30520: Participant defines used distribution model

**L1 requirement (high-level requirement)** · Status **Defined**

**Trace:** [SA01](../../README.md) › [SIMPL-16074](../README.md) (L0) › **SIMPL-30520** (L1)

## Text

Simpl-Open shall allow a Participant to configure, for each workflow, the distribution model and required distribution parameters, including infrastructure target, based on data volume and processing complexity.
