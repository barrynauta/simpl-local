# SIMPL-30523: Participant defines workflow distribution model

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-30520](../README.md) (L1) › **SIMPL-30523** (L2)

## Text

Simpl-Open shall allow a *Participant* to define the workflow distribution model, i.e., this model treats each data workflow as a single, indivisible unit.
