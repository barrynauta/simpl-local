# SIMPL-19317: Participant deletes a data orchestration workflow

**L2 requirement (detailed requirement)**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19290](../README.md) (L1) › **SIMPL-19317** (L2)

## Text

Simpl‑Open shall allow a Provider to delete a data orchestration workflow. Simpl-Open shall provide information on dependencies and constraints affecting the deletion of a data orchestration workflow, enabling the Provider to make an informed decision. Simpl-Open shall preserve logs of past executions of deleted workflows.
