# SIMPL-19292: Participant monitors and accesses data orchestration workflow execution logs

**L1 requirement (high-level requirement)** · Status **Defined**

**Trace:** [SA01](../../README.md) › [SIMPL-16074](../README.md) (L0) › **SIMPL-19292** (L1)
