# SIMPL-19322: Participant monitors a data orchestration workflow

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19292](../README.md) (L1) › **SIMPL-19322** (L2)

## Text

Simpl shall provide monitoring capabilities that enable the Participant to observe the execution of data orchestration workflows, both during execution and retrospectively, including access to execution logs, data orchestration workflow status indicators, error and exception reporting, and historical run data for audit and troubleshooting purposes. Logs and status information shall be visible as they are produced by the services, and only to Participants who are authorized to view them. Execution logs and historical monitoring data shall remain available for authorized Participants even if the corresponding data orchestration workflow has been deleted, ensuring auditability and traceability.
