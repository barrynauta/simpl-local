# SIMPL-19321: Participant captures data orchestration workflow execution logs

**L2 requirement (detailed requirement)**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19292](../README.md) (L1) › **SIMPL-19321** (L2)

## Text

Simpl shall provide capabilities to capture and store detailed execution logs of data orchestration workflows. Logs shall be made available to Participants during data orchestration workflow execution and retrospectively for auditing, troubleshooting, and compliance purposes.
