# SIMPL-30560: Participant executes workflow on saved distribution configuration

**L1 requirement (high-level requirement)**

**Trace:** [SA01](../../README.md) › [SIMPL-16074](../README.md) (L0) › **SIMPL-30560** (L1)

## What this item is

This L1 requirement covers running a data workflow with the distribution model and infrastructure target that were saved when the workflow was defined. It belongs to [SA01 Data orchestration used by a Participant](https://code.europa.eu/simpl/simpl-open/foundations/business-processes/-/blob/main/sa01-data-orchestration/README.md).

## Text

Simpl-Open shall execute the workflow using the distribution model and infrastructure target saved during workflow definition.
