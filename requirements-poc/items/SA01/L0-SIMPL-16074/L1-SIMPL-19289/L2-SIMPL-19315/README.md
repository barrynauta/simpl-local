# SIMPL-19315: Participant creates a new version of a data orchestration workflow

**L2 requirement (detailed requirement)**

**Trace:** [SA01](../../../README.md) › [SIMPL-16074](../../README.md) (L0) › [SIMPL-19289](../README.md) (L1) › **SIMPL-19315** (L2)

## Text

Simpl‑Open shall provide Providers with the capability to create new versions of existing data orchestration workflows, including modifying workflow steps, sequencing and business logic.
