# SIMPL-1277: Authentication process - IAA

**L1 requirement (high-level requirement)** · Status **In Progress**

**Trace:** [BP13](../../README.md) › [SIMPL-10783](../README.md) (L0) › **SIMPL-1277** (L1)

## Text

The information system and technology shall support the data space participant Authentication process.

The authentication process requires the technology layer of three different participants in the data space: requestor, identity Authority, and verifying party
