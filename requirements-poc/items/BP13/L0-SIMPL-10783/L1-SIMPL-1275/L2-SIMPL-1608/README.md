# SIMPL-1608: Agent initialisation

**L2 requirement (detailed functionality)** · Status **Defined**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-1275](../README.md) (L1) › **SIMPL-1608** (L2)

## Text

Simpl shall provide a set of semi-automated instructions or guidelines where:

- a user, in charge to set up a Simpl agent, can set up a minimal set of components useful to have a functional Simpl agent
