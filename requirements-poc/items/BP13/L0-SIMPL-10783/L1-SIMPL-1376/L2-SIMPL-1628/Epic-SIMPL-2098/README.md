# SIMPL-2098: Ensure Standards Compliance for Container's Orchestration Platform

**Epic (deliverable, testable feature)** · Status **In Preparation**

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1376](../../README.md) (L1) › [SIMPL-1628](../README.md) (L2) › **SIMPL-2098** (Epic)

## Text

**As a** Data Space Governance Authority\
**I want to** provide industry standards for the Simpl Consumer Agent\
**So that** Consumers can confidently deploy the Consumer Agent on a supported container orchestration platform.

AC:

Documentation outlining the standards to be linked and shared across DG Connect, PSO and SC1.
