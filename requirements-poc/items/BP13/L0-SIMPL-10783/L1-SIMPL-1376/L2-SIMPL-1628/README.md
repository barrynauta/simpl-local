# SIMPL-1628: Containerisation ready

**L2 requirement (detailed requirement)**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-1376](../README.md) (L1) › **SIMPL-1628** (L2)

## Text

Simpl shall:

- Be available in container image format, to be operable in orchestration environments.
- Offer a trusted Container Registry integration, from which the Container Image could be pulled.
- Comply with de facto standards for security, simplicity, and portability.
- Provide configurable capabilities for the agent.
- provide scripts to automatically deploy the agent on orchestration platforms.
