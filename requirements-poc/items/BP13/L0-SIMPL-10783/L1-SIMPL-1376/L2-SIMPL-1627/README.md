# SIMPL-1627: Virtualisation ready

**L2 requirement (detailed requirement)**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-1376](../README.md) (L1) › **SIMPL-1627** (L2)

## Text

Simpl shall:

- Be available in Linux Virtual Machine Image format, to be operable in virtualisation platforms.
- Offer a trusted VM repository, from which the VM image can be retrieved.
- Comply with de facto standards for security, simplicity, and portability.
- Provide configurable capabilities for the agent.
- Provide scripts to automatically deploy the agent on virtualisation platforms.
