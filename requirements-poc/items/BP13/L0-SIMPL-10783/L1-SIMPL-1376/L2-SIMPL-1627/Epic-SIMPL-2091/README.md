# SIMPL-2091: Select a Standard for the building and registry of the Agent image

**Epic (deliverable, testable feature)** · Status **For DG Connect Review**

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1376](../../README.md) (L1) › [SIMPL-1627](../README.md) (L2) › **SIMPL-2091** (Epic)

## Text

**As a** Data Space Governance Authority\
**I want to** provide industry standards for the building and registry of the container Agent image\
**So that** Consumers can confidently deploy the Consumer Agent on a supported container orchestration platform.

-

**Acceptance Criterion**

Documentation outlining the standards to be linked and shared across DG Connect, PSO and SC1.
