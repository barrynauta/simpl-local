# SIMPL-2094: Deploy Simpl on Virtualization Platforms

**Epic (deliverable, testable feature)** · Status **Cancelled**

> 🔴 **Cancelled.** Kept here for history. It is not part of the current requirements.

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1376](../../README.md) (L1) › [SIMPL-1627](../README.md) (L2) › **SIMPL-2094** (Epic)

## Text

**As an** Infrastructure Consumer,\
**I want to** deploy Simpl on virtualization platforms using the provided VM image,\
**So that** I can utilise Simpl's services within my virtualized environment.

AC: Given that Infrastructure Consumers require Simpl on virtualization platforms,\
When they access and deploy the provided VM image,\
Then they can run Simpl services in their virtualized environment efficiently.
