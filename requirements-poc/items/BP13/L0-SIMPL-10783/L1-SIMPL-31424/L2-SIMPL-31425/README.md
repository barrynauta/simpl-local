# SIMPL-31425: Governance authority registers participants' contact email

**L2 requirement (detailed requirement)** · Status **In Progress**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-31424](../README.md) (L1) › **SIMPL-31425** (L2)

## What this item is

This L2 details the first part of SIMPL-31424: the participant contact email is asked for in the onboarding request and stored with the participant profile.

## Text

Simpl shall require an Applicant to input a dedicated contact email address for the participant as part of the onboarding request, distinct from the Applicant's own email address, and associate this contact email with the participant profile once the onboarding request is approved.
