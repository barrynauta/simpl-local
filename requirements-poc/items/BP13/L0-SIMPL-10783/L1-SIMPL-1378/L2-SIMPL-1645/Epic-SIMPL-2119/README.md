# SIMPL-2119: A Participant integrates their Simpl-Open agent with software firewall solutions

**Epic (deliverable, testable feature)** · Status **Defined**

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1378](../../README.md) (L1) › [SIMPL-1645](../README.md) (L2) › **SIMPL-2119** (Epic)

## Text

**As a** Participant\
**I want to** integrate my Simpl-Open agent with existing enterprise firewalls or cloud‑native security groups\
**So that** I can protect my Simpl-Open Agent from external infrastructure threats (Outer Agent Firewall) and securing the microservices internally (Inner Agent Firewall).

**Acceptance Criteria**

Firewall configuration and operation are the responsibility of the Participant. Simpl-Open will support the Participant by providing documentation about ensuring the required network security rules such as protocols and ports, as well as operational aspects such as logging and auditing.
