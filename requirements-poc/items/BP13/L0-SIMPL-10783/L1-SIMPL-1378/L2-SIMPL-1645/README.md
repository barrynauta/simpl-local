# SIMPL-1645: A Participant integrates their Simpl-Open agent with software firewall solutions

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-1378](../README.md) (L1) › **SIMPL-1645** (L2)

## Text

Simpl‑Open shall support a Participant to integrate their Simpl-Open agent with existing enterprise firewalls or cloud‑native security groups to protect the Simpl-Open Agent from external infrastructure threats (Outer Agent Firewall) and securing the microservices internally (Inner Agent Firewall).

Firewall configuration and operation are the responsibility of the Participant. Simpl-Open will support the Participant by providing documentation about the required network security rules such as protocols and ports.
