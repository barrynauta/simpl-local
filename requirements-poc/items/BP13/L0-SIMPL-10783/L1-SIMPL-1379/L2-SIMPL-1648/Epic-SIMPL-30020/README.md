# SIMPL-30020: A Consumer sets the VPN configuration for data transfer between their Simpl-Open agent and the data resource destination

**Epic (deliverable, testable feature)** · Status **Defined**

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1379](../../README.md) (L1) › [SIMPL-1648](../README.md) (L2) › **SIMPL-30020** (Epic)

## Text

**As a** Consumer\
**I want to** set the VPN configuration for data transfer between the Simpl-Open agent and data resource destination.\
**So that** I can ensure that my data resource is securely transferred from the Simpl-Open agent of the Consumer to the data resource destination.

**Acceptance criteria**

Documentation will be provided on how the Consumer needs to set the VPN configuration for data transfer between the Simpl-Open agent and data resource destination.
