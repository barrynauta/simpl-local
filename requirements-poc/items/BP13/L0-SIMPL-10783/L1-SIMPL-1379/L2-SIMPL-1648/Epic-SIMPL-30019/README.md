# SIMPL-30019: A Provider sets the VPN configuration for data transfer between the data resource source and their Simpl-Open agent

**Epic (deliverable, testable feature)** · Status **Defined**

**Trace:** [BP13](../../../../README.md) › [SIMPL-10783](../../../README.md) (L0) › [SIMPL-1379](../../README.md) (L1) › [SIMPL-1648](../README.md) (L2) › **SIMPL-30019** (Epic)

## Text

**As a** Provider\
**I want** to set the VPN configuration for data transfer between the data resource source **and** the Simpl-Open agent.\
**So that** I can ensure that my data resource is securely transferred from the data resource source to the Simpl-Open agent of the Provider.

**Acceptance criteria**

Documentation will be provided on how the Provider needs to set the VPN configuration for data transfer between the data resource source and the Simpl-Open agent.
