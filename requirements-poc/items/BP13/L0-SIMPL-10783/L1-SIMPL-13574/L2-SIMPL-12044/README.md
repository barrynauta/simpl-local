# SIMPL-12044: A Participant uses the Simpl-Open landing page adapted to their Participant type

**L2 requirement (detailed requirement)**

**Trace:** [BP13](../../../README.md) › [SIMPL-10783](../../README.md) (L0) › [SIMPL-13574](../README.md) (L1) › **SIMPL-12044** (L2)

## Text

Simpl-Open shall allow a Participant to use a landing page consisting of an interface showing the relevant functionalities adapted to the Participant type logged in.

The landing page redirects the Participants to the UI of a chosen functionality.

There is a distinct landing page for: Governance Authority, Data Provider, Application Provider, Infrastructure Provider, Consumer.
