# SIMPL-27195: Data Provider withdraws and reactivates consent assertions

**L2 requirement (detailed functionality)** · Status **In Progress**

**Trace:** [SA09](../../../README.md) › [SIMPL-26074](../../README.md) (L0) › [SIMPL-26083](../README.md) (L1) › **SIMPL-27195** (L2)

## Text

Simpl shall enable a Data Provider to withdraw or reactivate a consent assertion, requiring a reason to be provided. Upon each status change, Simpl shall notify all bound Consumers, communicating the reason and informing them that the dataset is no longer accessible for consumption in the case of a withdrawal, or that a new compliant version is available for ingestion in the case of a reactivation.
