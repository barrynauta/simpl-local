# SIMPL-26083: Data Provider manages consent assertion status changes

**L1 requirement (high-level requirement)**

**Trace:** [SA09](../../README.md) › [SIMPL-26074](../README.md) (L0) › **SIMPL-26083** (L1)

## Text

Simpl shall enable a Data Provider to withdraw and reactivate consent assertions, allowing their status to be evaluated during policy enforcement and access-control processes.
