# SIMPL-27154: Data Provider creates resource consent assertions for shared data resources

**L2 requirement (detailed requirement)**

**Trace:** [SA09](../../../README.md) › [SIMPL-26074](../../README.md) (L0) › [SIMPL-27082](../README.md) (L1) › **SIMPL-27154** (L2)

## Text

Simpl shall enable a Data Provider to associate a consent assertion with a Data Resource Description. The consent assertion status may be evaluated during policy enforcement and access-control processes.
