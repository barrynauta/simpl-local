# SIMPL-27082: Data Provider manages consent assertions for shared data resources

**L1 requirement (high-level requirement)**

**Trace:** [SA09](../../README.md) › [SIMPL-26074](../README.md) (L0) › **SIMPL-27082** (L1)

## Text

Simpl shall enable a Data Provider to create and manage consent assertions associated with datasets, so that consent-related information can be consulted and maintained within the platform.
