# SIMPL-30295: Data provider manages consent assertions - Improvement

**Epic (deliverable, testable feature)**

**Trace:** [SA09](../../../../README.md) › [SIMPL-26074](../../../README.md) (L0) › [SIMPL-27082](../../README.md) (L1) › [SIMPL-27156](../README.md) (L2) › **SIMPL-30295** (Epic)

## Text

*This Epic is needed to improve SIMPL-27206 and SIMPL-27205 to allow users managing resource descriptions and users managing contracts to also: 1) view consent assertions 2) update the status of a resource or contract consent assertion, respectively. Since the specific roles must not be mentioned in Epics, this Epic will not contain new ACS and will just collect the user stories related to the above improvements.*
