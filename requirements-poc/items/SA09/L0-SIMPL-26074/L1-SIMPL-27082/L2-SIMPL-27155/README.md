# SIMPL-27155: Data Provider creates contract consent assertions for shared data resources

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [SA09](../../../README.md) › [SIMPL-26074](../../README.md) (L0) › [SIMPL-27082](../README.md) (L1) › **SIMPL-27155** (L2)

## Text

Simpl shall enable a Data Provider to create a contract consent assertion linked to a specific contract, allowing consent-related assertion information to be evaluated during policy enforcement and access-control processes for the Consumer bound by that contract, independently of the dataset’s overall consent assertion status.
