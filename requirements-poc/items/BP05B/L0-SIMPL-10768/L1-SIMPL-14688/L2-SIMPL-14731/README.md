# SIMPL-14731: A Provider adds common metadata to a new Resource description

**L2 requirement (detailed requirement)**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14688](../README.md) (L1) › **SIMPL-14731** (L2)

## Text

Simpl-Open shall allow and support a Provider via UI and API

- to add common metadata, which are present for every type of Resource, to a new Resource description.
