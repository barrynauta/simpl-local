# SIMPL-29315: A Provider adds a new access policy template

**Epic (deliverable, testable feature)** · Status **In Progress**

**Trace:** [BP05B](../../../../README.md) › [SIMPL-10768](../../../README.md) (L0) › [SIMPL-14688](../../README.md) (L1) › [SIMPL-14733](../README.md) (L2) › **SIMPL-29315** (Epic)

## Text

**As a** Provider\
**I want to** add a new access policy template\
**so that** I can use that when I assign an access policy in a resource description.

**Acceptance Criterion: Create a new access policy template through configuration**

The Provider can define a new access policy template through configuration. Simpl-Open will support the Provider by providing documentation and an example on

- how to create a new access policy template for contracting and consumption
- how to create an extension for the connector
- how to register the extension to the connector and bind it to that policy template
