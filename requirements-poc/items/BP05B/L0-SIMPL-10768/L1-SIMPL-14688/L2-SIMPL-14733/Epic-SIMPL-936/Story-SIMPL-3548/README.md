# SIMPL-3548: [UI] Access Policy possible to define Prohibitions

**User story (implementable work)** · Status **PBI Cancelled**

> 🔴 **Cancelled.** Kept here for history. It is not part of the current requirements.

**Trace:** [BP05B](../../../../../README.md) › [SIMPL-10768](../../../../README.md) (L0) › [SIMPL-14688](../../../README.md) (L1) › [SIMPL-14733](../../README.md) (L2) › [SIMPL-936](../README.md) (Epic) › **SIMPL-3548** (User story)

## Text

**As a** Provider User,\
**I want to** use the UI to define negative rules on the access policy, i.e., prohibit specific user with the attributes from actions.\
**So that** I can define the access policy that restrict the access for specific attributes.

-----------------------------------

**Technical Details**

(image not shown)

The UI should allow to add two different types of rules (Permissions) and the new Prohibitions. It should clearly indicate if a rule is a permission or prohibition. If the rules are send to the API they should be send in two different lists one containing the permissions and one the prohibitions.
