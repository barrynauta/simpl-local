# SIMPL-14750: The Governance Authority provides feedback to a Provider about semantic validation errors

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14687](../README.md) (L1) › **SIMPL-14750** (L2)

## Text

Simpl-Open shall support the Governance Authority

- to automatically provide feedback to a Provider about semantic validation errors in submitted Resource descriptions.
