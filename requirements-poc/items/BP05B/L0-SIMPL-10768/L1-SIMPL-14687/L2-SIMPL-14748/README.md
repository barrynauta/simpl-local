# SIMPL-14748: The Governance Authority provides feedback to a Provider about syntax validation errors

**L2 requirement (detailed requirement)**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14687](../README.md) (L1) › **SIMPL-14748** (L2)

## Text

Simpl-Open shall support the Governance Authority

- to automatically provide feedback to a Provider about syntax validation errors in a submitted Resource description.
