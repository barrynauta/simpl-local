# SIMPL-14640: The Governance Authority revokes a resource description

**L1 requirement (high-level requirement)**

**Trace:** [BP05B](../../README.md) › [SIMPL-10768](../README.md) (L0) › **SIMPL-14640** (L1)

## Text

Simpl-Open shall support the Governance Authority

- to revoke Resource descriptions on request of the provider
- to notify Consumers about the revocation.
