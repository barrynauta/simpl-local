# SIMPL-14738: A Provider updates the common metadata of a new version of a Resource description

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14728](../README.md) (L1) › **SIMPL-14738** (L2)

## Text

Simpl-Open shall allow a Provider via an UI and an API

- to update the common metadata, which are present for every type of Resource, in a new version of a Resource description.
