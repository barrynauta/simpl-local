# SIMPL-14699: A Provider requests the revocation of a Resource description

**L1 requirement (high-level requirement)** · Status **Defined**

**Trace:** [BP05B](../../README.md) › [SIMPL-10768](../README.md) (L0) › **SIMPL-14699** (L1)

## Text

Simpl-Open shall allow a Provider

- to request to the Governance Authority the revocation of a previously published Resource description.
