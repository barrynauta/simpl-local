# 5B.3 - A Provider creates a new version of a Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b3-provider-creates-new-version-resource-description](https://simpl-programme.ec.europa.eu/book-page/tbp-5b3-provider-creates-new-version-resource-description)

## Description

Simpl-Open shall allow a Provider to create a new version of a previously published Resource description based on the latest version of the schema for the resource type of that Resource Description.

## Detailed Requirements

- **5B.3.1 – A Provider updates the common metadata of a new version of a Resource description** — Simpl-Open shall allow a Provider via UI and API to update common metadata. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b31-provider-updates-common-metadata-new-version-resource-description)
- **5B.3.2 – A Provider updates the resource type specific metadata of a new version of a Resource description** — Simpl-Open shall allow a Provider via UI and API to update resource type-specific metadata. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b32-provider-updates-resource-type-specific-metadata-new-version-resource)
- **5B.3.3 – A Provider updates the access policies of a new version of a Resource description** — Simpl-Open shall allow a Provider via UI and API to update access policies. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b33-provider-updates-access-policies-new-version-resource-description)
- **5B.3.4 – A Provider updates the usage policies of a new version of a Resource description** — Simpl-Open shall allow a Provider via UI and API to update usage policies. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b34-provider-updates-usage-policies-new-version-resource-description)
- **5B.3.5 – A Provider updates the set of contract clauses of a new version of a resource description** — Simpl-Open shall allow a Provider via UI and API to update contract clauses. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b35-provider-updates-set-contract-clauses-new-version-resource-description)
