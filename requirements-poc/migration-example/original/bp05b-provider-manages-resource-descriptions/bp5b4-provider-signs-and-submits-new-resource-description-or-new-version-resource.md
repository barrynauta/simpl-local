# 5B.4 - A Provider signs and submits a new Resource description or a new version of a Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b4-provider-signs-and-submits-new-resource-description-or-new-version-resource](https://simpl-programme.ec.europa.eu/book-page/tbp-5b4-provider-signs-and-submits-new-resource-description-or-new-version-resource)

## Description

Simpl-Open shall enable Providers to:

- Sign a new resource description or a new version of a resource description.
- Submit a new resource description or a new version of a resource description to the Governance Authority for publication.

## Detailed Requirements

- **5B.4.1 – A Provider signs and submits a new Resource description or a new version of a Resource description** — Simpl-Open shall allow a Provider via UI and API to sign and submit resource descriptions.
