# 5B.5 - The Governance Authority publishes a Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b5-governance-authority-publishes-resource-description](https://simpl-programme.ec.europa.eu/book-page/tbp-5b5-governance-authority-publishes-resource-description)

## Description

Simpl-Open shall support the Governance Authority to publish a Resource description submitted via an API by a Provider.

## Detailed Requirements

- **5B.5.1 – The Governance Authority validates the schema** — Supports schema validation for new Resource descriptions or versions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b51-governance-authority-validates-schema-new-resource-description-or-new-version)
- **5B.5.2 – The Governance Authority notifies about inactive schema** — Alerts providers to schema status issues. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b52-governance-authority-notifies-provider-about-inactive-schema)
- **5B.5.3 – The Governance Authority validates versioning** — Ensures proper version management for Resource descriptions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b53-governance-authority-validates-versioning-new-version-resource-description)
- **5B.5.4 – Notifies about wrong versioning** — Alerts providers to versioning errors. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b54-governance-authority-notifies-provider-about-wrong-versioning-new-versions)
- **5B.5.5 – Validates syntax** — Checks syntax compliance for descriptions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b55-governance-authority-validates-syntax-new-resource-description-or-new-version)
- **5B.5.6 – Notifies about syntax errors** — Communicates validation failures to providers. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b56-governance-authority-notifies-provider-about-syntax-validation-errors)
- **5B.5.7 – Validates semantics** — Ensures semantic correctness of descriptions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b57-governance-authority-validates-semantics-new-resource-description-or-new-version)
- **5B.5.8 – Notifies about semantic errors** — Reports semantic validation issues. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b58-governance-authority-notifies-provider-about-semantic-validation-errors)
- **5B.5.9 – Publishes Resource description** — Finalises publication of approved descriptions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b59-governance-authority-publishes-new-resource-description-or-new-version-resource)
- **5B.5.10 – Revokes previous version** — Manages superseded description versions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b510-governance-authority-revokes-previous-version-resource-description)
- **5B.5.11 – Evaluates metadata quality** — Assesses quality of description metadata. [Details](https://simpl-programme.ec.europa.eu/book-page/5b511-governance-authority-evaluates-metadata-quality-new-resource-description-or-new)
- **5B.5.12 – Notifies about metadata quality** — Communicates quality assessment results. [Details](https://simpl-programme.ec.europa.eu/book-page/5b512-governance-authority-notifies-provider-about-metadata-quality)
- **5B.5.13 – Approves/rejects metadata** — Makes final decisions on description acceptance. [Details](https://simpl-programme.ec.europa.eu/book-page/5b513-governance-authority-approvesrejects-metadata-new-resource-description-or-new)
