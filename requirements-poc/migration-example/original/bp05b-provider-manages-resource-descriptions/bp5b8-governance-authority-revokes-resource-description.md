# 5B.8 - The Governance Authority revokes a resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/5b8-governance-authority-revokes-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b8-governance-authority-revokes-resource-description)

## Description

Simpl-Open shall enable the Governance Authority to:

- Revoke Resource descriptions upon provider request.
- Notify Consumers regarding the revocation.

## Detailed Requirements

- **5B.8.1 – The Governance Authority revokes a resource description** — Simpl-Open shall support the Governance Authority in revoking resource descriptions. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b61-governance-authority-revokes-resource-description)
