# 5B.9 - The Provider notifies Consumers about the revocation of a resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/5b9-provider-notifies-consumers-about-revocation-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b9-provider-notifies-consumers-about-revocation-resource-description)

## Description

Simpl-Open shall support a Provider to automatically notify Consumers of a resource about the revocation of the related resource description.

## Detailed Requirements

- **5B.9.1 – A Provider notifies Consumers about the revocation of a resource description** — Simpl-Open shall support a Provider to notify Consumers about revocation. [Details](https://simpl-programme.ec.europa.eu/book-page/5b91-provider-notifies-consumers-about-revocation-resource-description)
