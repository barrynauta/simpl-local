# 5B.6 - A Provider notifies Consumers about a new version of a Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/5b6-provider-notifies-consumers-about-new-version-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b6-provider-notifies-consumers-about-new-version-resource-description)

## Description

Simpl-Open shall provide support enabling a Provider to automatically notify Consumers of a resource about a new version of the related Resource description.

## Detailed Requirements

- **5B.6.1 – A Provider notifies Consumers about a new version of a Resource description** — Simpl-Open shall support a Provider in notifying Consumers regarding updated Resource description versions. [Details](https://simpl-programme.ec.europa.eu/book-page/5b61-provider-notifies-consumers-about-new-version-resource-description)
