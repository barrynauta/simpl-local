# 5B.8 - The Governance Authority revokes a resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/5b8-governance-authority-revokes-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b8-governance-authority-revokes-resource-description)

## About this requirement

This is high-level requirement 5B.8 of business process [BP05B - Provider manages resource descriptions](./README.md). In the backlog it is item SIMPL-14640, status **Defined**. The status is the one in the backlog (Jira). The requirements site shows all requirements as Proposed.

In the process it covers 1 step: [BP05B.14 Revoke a resource description](./README.md#bp05b14-revoke-a-resource-description). The dynamic view shows it in [Revoke a self-description](bp05b-dynamic-view.md#revoke-a-self-description-sd).

It is split into 1 detailed requirement, delivered through 1 Epic with 2 user stories in total. Each detailed requirement below says what Simpl-Open must do. Under it are its Epics: open one to read its user stories and their acceptance criteria.

## Description

Simpl-Open shall support the Governance Authority

- to revoke Resource descriptions on request of the provider
- to notify Consumers about the revocation.
