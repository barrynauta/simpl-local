# 5B.6 - A Provider notifies Consumers about a new version of a Resource description

[https://simpl-programme.ec.europa.eu/book-page/5b6-provider-notifies-consumers-about-new-version-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b6-provider-notifies-consumers-about-new-version-resource-description)

## About this requirement

This is high-level requirement 5B.6 of business process [BP05B - Provider manages resource descriptions](./README.md). In the backlog (Jira) it is item SIMPL-21118.

In the process it covers 1 step: [BP05B.12 Inform about new version](./README.md#bp05b12-inform-about-new-version). There is no dynamic view for it yet.

It is split into 1 detailed requirement, delivered through 1 Epic with 1 user story in total. Each detailed requirement below says what Simpl-Open must do. Under it are its Epics: open one to read its user stories and their acceptance criteria.

## Description

Simpl-Open shall support a Provider

- to automatically notify Consumers of a resource about a new version of the related Resource description.
