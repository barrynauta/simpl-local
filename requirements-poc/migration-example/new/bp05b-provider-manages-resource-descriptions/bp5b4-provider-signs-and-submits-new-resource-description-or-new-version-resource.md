# 5B.4 - A Provider signs and submits a new Resource description or a new version of a Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b4-provider-signs-and-submits-new-resource-description-or-new-version-resource](https://simpl-programme.ec.europa.eu/book-page/tbp-5b4-provider-signs-and-submits-new-resource-description-or-new-version-resource)

## About this requirement

This is high-level requirement 5B.4 of business process [BP05B - Provider manages resource descriptions](./README.md). In the backlog (Jira) it is item SIMPL-14729.

In the process it covers 1 step: [BP05B.04 Sign and submit the resource description](./README.md#bp05b04-sign-and-submit-the-resource-description). The dynamic view shows it in [Define and publish self-description](bp05b-dynamic-view.md#define-and-publish-self-description) and [the technology components view](bp05b-tcv-dynamic-view.md).

It is split into 1 detailed requirement, delivered through 2 Epics with 13 user stories in total. Each detailed requirement below says what Simpl-Open must do. Under it are its Epics: open one to read its user stories and their acceptance criteria.

## Description

Simpl-Open shall allow a Provider

- to sign a new resource description or a new version of a resource description
- to submit a new resource description or a new version of a resource description to the Governance authority for publication.
