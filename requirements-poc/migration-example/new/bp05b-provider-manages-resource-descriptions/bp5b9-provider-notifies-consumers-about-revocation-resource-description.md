# 5B.9 - The Provider notifies Consumers about the revocation of a resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/5b9-provider-notifies-consumers-about-revocation-resource-description](https://simpl-programme.ec.europa.eu/book-page/5b9-provider-notifies-consumers-about-revocation-resource-description)

## About this requirement

This is high-level requirement 5B.9 of business process [BP05B - Provider manages resource descriptions](./README.md). In the backlog (Jira) it is item SIMPL-21117.

In the process it covers 1 step: [BP05B.15 Inform about revocation](./README.md#bp05b15-inform-about-revocation). There is no dynamic view for it yet.

It is split into 1 detailed requirement, delivered through 1 Epic with 2 user stories in total. Each detailed requirement below says what Simpl-Open must do. Under it are its Epics: open one to read its user stories and their acceptance criteria.

## Description

Simpl-Open shall support a Provider

- to automatically notify Consumers of a resource about the revocation of the related resource description.
