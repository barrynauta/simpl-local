# SIMPL-14639: A Provider requests the revocation of a resource description

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14699](../README.md) (L1) › **SIMPL-14639** (L2)

**On the requirements site:** 5B.7.1

## Text

Simpl-Open shall allow a Provider via UI and an API

- to request from the Governance authority the revocation of a previously published Resource description.
