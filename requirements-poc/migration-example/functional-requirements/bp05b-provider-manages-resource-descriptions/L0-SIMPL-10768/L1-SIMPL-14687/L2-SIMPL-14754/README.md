# SIMPL-14754: The Governance Authority revokes the previous version of a Resource description

**L2 requirement (detailed requirement)** · Status **Defined**

**Trace:** [BP05B](../../../README.md) › [SIMPL-10768](../../README.md) (L0) › [SIMPL-14687](../README.md) (L1) › **SIMPL-14754** (L2)

**On the requirements site:** 5B.5.10

## Text

Simpl-Open shall support the Governance Authority

- to automatically revoke the previous version of a Resource Description, if a new resource version of a Resource  description is published.
