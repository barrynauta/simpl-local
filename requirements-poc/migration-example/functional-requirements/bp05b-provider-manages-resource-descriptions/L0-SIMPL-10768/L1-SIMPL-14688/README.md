# SIMPL-14688: A Provider creates a new Resource description

**L1 requirement (high-level requirement)** · Status **In Progress**

**Trace:** [BP05B](../../README.md) › [SIMPL-10768](../README.md) (L0) › **SIMPL-14688** (L1)

**On the requirements site:** 5B.2 · **Process steps:** [BP05B.01](../../../../business-processes/bp05b-provider-manages-resource-descriptions/README.md#bp05b01-create-a-new-resource-description), [BP05B.02](../../../../business-processes/bp05b-provider-manages-resource-descriptions/README.md#bp05b02-add-resource-type-specific-metadata), [BP05B.03](../../../../business-processes/bp05b-provider-manages-resource-descriptions/README.md#bp05b03-add-policy-and-contract-related-metadata) · **Dynamic view:** [Define and publish self-description](../../../../business-processes/bp05b-provider-manages-resource-descriptions/bp05b-dynamic-view.md#define-and-publish-self-description), [technology components](../../../../business-processes/bp05b-provider-manages-resource-descriptions/bp05b-tcv-dynamic-view.md)

## Text

Simpl-Open shall allow a Provider

- to create new resource descriptions based on the latest versions of the resource description schema for the resource types.
