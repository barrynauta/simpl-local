# SIMPL-30655: A Provider adds contract clauses to a new Resource description via UI [Extension]

**Epic (deliverable, testable feature)** · Status **Defined**

**Trace:** [BP05B](../../../../README.md) › [SIMPL-10768](../../../README.md) (L0) › [SIMPL-14688](../../README.md) (L1) › [SIMPL-14736](../README.md) (L2) › **SIMPL-30655** (Epic)

## Text

This epic extends the creation and association of contract clauses to a new resource description via UI, by allowing the Provider to remove contract clauses before submitting the resource description.
