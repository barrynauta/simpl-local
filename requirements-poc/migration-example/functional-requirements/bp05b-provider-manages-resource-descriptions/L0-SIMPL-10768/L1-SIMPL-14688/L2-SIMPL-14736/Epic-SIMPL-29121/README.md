# SIMPL-29121: A Provider defines an information point to monitor SLAs

**Epic (deliverable, testable feature)** · Status **Defined**

**Trace:** [BP05B](../../../../README.md) › [SIMPL-10768](../../../README.md) (L0) › [SIMPL-14688](../../README.md) (L1) › [SIMPL-14736](../README.md) (L2) › **SIMPL-29121** (Epic)

## Text

**As a** Provider\
**I want to** define an SLA information point based on the consumption logs of my resources and other relevant logs\
**So that** I can include the SLA information point in the contract clause SLA

and assess whether I am providing the performance as promised in the usage contract

**Acceptance criteria:**

The Provider can define endpoints that use aggregations of consumption logs and other relevant logs to track the performance of a resource related to the performance targets from the SLA. Simpl-Open will support the Participant by providing documentation on how to create such endpoints.
