# SIMPL-14729: A Provider signs and submits a new Resource description or a new version of a Resource description

**L1 requirement (high-level requirement)** · Status **Defined**

**Trace:** [BP05B](../../README.md) › [SIMPL-10768](../README.md) (L0) › **SIMPL-14729** (L1)

**On the requirements site:** 5B.4 · **Process steps:** [BP05B.04](../../../../business-processes/bp05b-provider-manages-resource-descriptions/README.md#bp05b04-sign-and-submit-the-resource-description) · **Dynamic view:** [Define and publish self-description](../../../../business-processes/bp05b-provider-manages-resource-descriptions/bp05b-dynamic-view.md#define-and-publish-self-description), [technology components](../../../../business-processes/bp05b-provider-manages-resource-descriptions/bp05b-tcv-dynamic-view.md)

## Text

Simpl-Open shall allow a Provider

- to sign a new resource description or a new version of a resource description
- to submit a new resource description or a new version of a resource description to the Governance authority for publication.
