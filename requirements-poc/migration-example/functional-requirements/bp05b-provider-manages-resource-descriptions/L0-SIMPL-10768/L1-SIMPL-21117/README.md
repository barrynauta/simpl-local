# SIMPL-21117: The Provider notifies Consumers about the revocation of a resource description

**L1 requirement (high-level requirement)** · Status **In Progress**

**Trace:** [BP05B](../../README.md) › [SIMPL-10768](../README.md) (L0) › **SIMPL-21117** (L1)

**On the requirements site:** 5B.9 · **Process steps:** [BP05B.15](../../../../business-processes/bp05b-provider-manages-resource-descriptions/README.md#bp05b15-inform-about-revocation)

## Text

Simpl-Open shall support a Provider

- to automatically notify Consumers of a resource about the revocation of the related resource description.
