# SIMPL-35863: [API] Create API for contract validation result
- Status: New Product Backlog Item
- Type: Story
- Created: 2026-10-26, updated: 2026-10-26
- Source: https://jira.simplprogramme.eu/browse/SIMPL-35863 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Contract Manager on consumer or provider side

**I want** to inform EDC about the result of VC validation

**So that** EDC will be able to continue the contract establishment process based on the validation result.

Acceptance Criteria:

AC1: EDC receives the VC validation result

**Given** the EDC of a data space participant with an API endpoint for reporting VC validation results

**When** the CM sends a POST request to the API endpoint: `/isValid/{contractNegotiationId}/{isValid}`

**Then** the EDC API accepts the validation result for the given contract negotiation

**And** the `isValid` parameter indicates whether the VC is valid (`true` or `false`)

**And** EDC continues the contract negotiation flow according to the validation result.

AC2: EDC receives the VC validation result (Negative scenario - Unauthorized)

**Given** the caller is not authenticated

**When** the caller sends a POST request to the API endpoint: `/isValid/{contractNegotiationId}/{isValid}`

**Then** the API returns a 401 Unauthorized response, indicating insufficient permissions.
