# SIMPL-35858: [API] Create API for contract existence verification
- Status: New Product Backlog Item
- Type: Story
- Created: 2026-10-26, updated: 2026-10-26
- Source: https://jira.simplprogramme.eu/browse/SIMPL-35858 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Contract Manager on consumer side

**I want** to inform EDC whether an active contract already exists for the requested resource

**So that** EDC will be able to determine whether the contract establishment process can continue.

Acceptance Criteria:

AC1: EDC verifies contract existence\
**Given** the EDC of a data space Consumer with an API endpoint for contract existence verification\
**When** the CM sends a POST request to the API endpoint: `/isPresent/{contractNegotiationId}/{isPresent}`\
**Then** the EDC API accepts the contract existence result (asynchronous) for the given contract negotiation\
**And** the `isPresent` parameter indicates whether an active contract exists (`true` or `false`)\
**And** EDC continues the contract negotiation flow according to the result.

AC2: EDC verifies contract existence (Negative scenario - Unauthorized)\
**Given** the caller is not authenticated\
**When** the caller sends a POST request to the API endpoint: `/isPresent/{contractNegotiationId}/{isPresent}`\
**Then** the API returns a 401 Unauthorized response, indicating insufficient permissions.
