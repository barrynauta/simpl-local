# SIMPL-35692: Contract UI backend will terminate unsigned contract offers after X days
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-10-22, updated: 2026-10-29
- Source: https://jira.simplprogramme.eu/browse/SIMPL-35692 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Contract UI backend\
**I want** to terminate all contract offers that are not finalized within the configured timeout (default 7 days)\
**So that** stale offers are closed and no longer presented to the user as pending

Acceptance Criteria:

**AC1: Scheduler terminates pending offers older than the timeout (Positive scenario)**\
**Given** the Contract UI backend has a configured timeout value (default 7 days)\
**When** there is a pending contract offer created more than the timeout ago and scheduler is executed\
**Then** the contract offer is terminated\
**And** the Contract Manager is informed, which calls the EDC endpoint /signed/{contractNegotiationId}/false to start the termination process on the EDC side

**AC2: Scheduler does not terminate recent offers (Negative scenario)**\
**Given** the Contract UI backend has a configured timeout value\
**When** a pending contract offer was created less than the timeout ago and scheduler is executed\
**Then** the contract offer is not terminated

**AC3: Scheduler does not terminate finalized contracts (Negative scenario)**\
**Given** the Contract UI backend has a configured timeout value\
**When** a contract offer older than the timeout is already finalized and scheduler is executed\
**Then** the contract is not changed

**AC4: Terminated offer is visible to the Consumer**\
**Given** a contract offer was terminated by the scheduler\
**When** the Consumer user opens the contract offers list in the Contract UI frontend (or uses contract UI backend API)\
**Then** the offer is shown with status Terminated

Technical Description:\
A new scheduler will be introduced in the Contract UI backend. It will:\
* Execute every day at 01:00 (configurable in application.properties and values.yaml)\
* Search for all contract offers in the Pending state that are older than the timeout, counted from the creation date in the Contract UI database (default 7 days, configurable in application.properties and values.yaml)\
* For each of them:\
** Mark it as terminated in contract UI database\
** Send a rejection request to the Contract Manager /contractOffers/{contractNegotiationId}/reject, which will propagate to the EDC connector (and will finally cause contract termination)
