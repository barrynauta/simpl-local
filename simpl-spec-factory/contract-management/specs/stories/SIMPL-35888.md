# SIMPL-35888: [API] Create API for VC exchange
- Status: New Product Backlog Item
- Type: Story
- Created: 2026-10-27, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-35888 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Contract Manager on consumer or provider side

**I want** to retrieve a Verifiable Credential (VC) from the other participant through EDC

**So that** I will be able to validate the VC and continue the contract establishment process.

Acceptance Criteria:

AC1: EDC retrieves a VC from the other participant

**Given** the EDC of a data space participant with an API endpoint for VC exchange

**When** the CM sends a GET request to the API endpoint: `/vcExchange/{contractNegotiationId}/request`

**Then** the API returns a 200 OK response

**And** the response contains the VC associated with the given `contractNegotiationId`

**And** EDC retrieves the VC from the other participant's EDC

**And** the VC is returned synchronously to the calling Contract Manager.

AC2: EDC retrieves a VC from the other participant (Negative scenario - Unauthorized)

**Given** the caller is not authenticated

**When** the caller sends a GET request to the API endpoint: `/vcExchange/{contractNegotiationId}/request`

**Then** the API returns a 401 Unauthorized response, indicating insufficient permissions.
