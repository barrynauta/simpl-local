# SIMPL-34633: [API] A Participant generates aggregated usage contract data for auditing purposes
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-10-12, updated: 2026-10-26
- Source: https://jira.simplprogramme.eu/browse/SIMPL-34633 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Participant,\
**I want** to automatically generate audit data and aggregations based on the usage contract data from the Participant according to a supplied audit rule package,\
**So that** the contract manager produces the audit data required by the Governance Authority through an endpoint\
and makes it available for storage in the local audit data repository of the Simpl-Open agent of the Participant

## Acceptance Criteria

**AC1 — Generate aggregations**

**Given** a Participant that onboarded to the data space\
**When** the contract manager database of the Participant contains at least one usage contract\
**Then** the contract manager produces the usage contract audit\
**And** makes it available through an endpoint for the logging & monitoring component of the Simpl-Open agent of the Participant

Note: the aggregated audit data produced by the contract manager consists of the amount of usage contracts per status at a given moment.
