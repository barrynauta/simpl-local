# SIMPL-30960: A Consumer consults the details of a usage contract via UI
- Status: PBI For DG Review
- Type: Story
- Created: 2026-07-30, updated: 2026-10-28
- Source: https://jira.simplprogramme.eu/browse/SIMPL-30960 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Consumer,\
**I want** to consult the details of a usage contract or usage contract offer via UI\
**So that** I can inspect the details of a usage contract or usage contract offer\
**And** I can decide whether to accept or reject a usage contract offer

Acceptance Criteria

AC1 - A Consumer consults the details of a usage contract or usage contract offer via UI

**Given** I am authenticated as a Consumer,\
**And** I have a role authorising the management of usage contracts,\
**And** I have opened the contract manager UI\
**When** I select a usage contract (offer) and click on a button to retrieve the usage contract (offer) details\
**Then** Simpl-Open returns the details of the selected usage contract offer overview with following information:\
* Contract negotiation ID;\
* Resource description ID;\
* Resource name;\
* Provider name;\
* Status (Requested, Rejected, Accepted, Signed, Active);\
* Human readable version of the usage contract (offer) (resource description properties, policies, contract clauses).

**And** I can click on a button to return to the overview screen
