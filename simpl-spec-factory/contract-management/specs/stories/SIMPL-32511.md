# SIMPL-32511: [API] - API to create usage contract offer
- Status: New Product Backlog Item
- Type: Story
- Created: 2026-09-03, updated: 2026-09-07
- Source: https://jira.simplprogramme.eu/browse/SIMPL-32511 (collected 2026-10-29)

## Description and acceptance criteria

New proposed: Replaces SIMPL-19829

**As a** Provider,\
**I want** to create a usage contract offer via API,\
**So that** I can provide the usage contract offer to the requesting Consumer for review

Acceptance Criteria

AC1 - A Provider creates a usage contract offer - positive case

**Given** a usage contract offer request\
**When** the usage contract offer is validated successfully (access policies, existence usage contract, resource consent status)\
**And** the POST /credentials/agreements/{contractAgreementId}/definitions/{contractDefinitionId}/create API is invoked\
**And** the body of the request contains\
contractNegotiationId (String)\
assetId (String)\
providerId (String)\
consumerId (String)\
contractOfferId (String)\
**Then** I receive a 201 Ok response\
**And** the usage contract offer overview is created\
**And** the body of the response contains\
contractAgreementId (UUID)\
contractDefinitionId (String)\
status: 'Requested' (String)\
contractNegotiationId (String)\
assetId (String)\
resourceDescriptionName (String)\
proverId (String)\
providerName (String)\
consumerId (String)\
consumerName (String)\
contractOfferId (String)\
usageContract (html)\
usageContractHash

AC2: A Provider creates a usage contract offer – error case (wrong assetId)

**Given** a usage contract offer request\
**When** the usage contract offer is validated successfully (access policies, existence usage contract, resource consent status)\
**And** the resource (assetId) in the request is not owned by the Provider\
**And** the POST /credentials/agreements/{contractAgreementId}/definitions/{contractDefinitionId}/create API is invoked\
**And** the body of the request contains\
contractNegotiationId (String)\
assetId (String)\
providerId (String)\
consumerId (String)\
contractOfferId (String)\
**Then** I receive a 403 Forbidden response

AC3: A Provider creates a usage contract offer – error case (assetId not found)

**Given** a usage contract offer request\
**When** the usage contract offer is validated successfully (access policies, existence usage contract, resource consent status)\
**And** the resource (assetId) in the request does not exist\
**And** the POST /credentials/agreements/{contractAgreementId}/definitions/{contractDefinitionId}/create API is invoked\
**And** the body of the request contains\
contractNegotiationId (String)\
assetId (String)\
providerId (String)\
consumerId (String)\
contractOfferId (String)\
**Then** I receive a 404 Not Found response
