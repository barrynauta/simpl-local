# SIMPL-30959: A Consumer consults an overview of their usage contracts via UI
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-07-30, updated: 2026-09-30
- Source: https://jira.simplprogramme.eu/browse/SIMPL-30959 (collected 2026-10-29)

## Description and acceptance criteria

**As a** Consumer,\
**I want** to consult an overview of my usage contracts and usage contract offers via UI,\
**So that** I can review the usage contract offers and decide whether to accept or reject it

Acceptance Criteria

AC1 - A Consumer consults an overview of their usage contracts via UI

**Given** I am authenticated as a Consumer,\
**And** I have a role authorising the management of usage contracts,\
**When** I open the contract manager UI,\
**Then** Simpl-Open returns an overview of all my usage contracts (including those still being established) with following information:\
* Contract negotiation ID;\
* Resource description ID;\
* Resource name;\
* Provider name;\
* Status (Requested, Rejected, Accepted, Signed, Active).

**And** I can click on a button to retrieve the usage contract details\
**And** I can click on a button to perform following actions on the usage contract offers with status 'Requested': 'Accept' or 'Reject'\
**And** I can filter based on Contract negotiation ID, resource name, Provider name, and status

AC2 - A Consumer consults an overview of their usage contracts via UI (No usage contract)

**Given** I am authenticated as a Consumer,\
**And** I have a role authorising the management of usage contracts,\
**And** I did not request any usage contracts yet\
**When** I open the contract manager UI,\
**Then** Simpl-Open returns the structure of the overview of my usage contracts in an empty table:\
* Contract negotiation ID;\
* Resource description ID;\
* Resource name;\
* Provider name;\
* Status (Requested, Rejected, Accepted, Signed, Active).

AC3 - A Consumer consults an overview of their usage contracts via UI (Negative case - not authorised)

**Given** I am not authenticated as Consumer with a role authorising the management of usage contracts\
**When** I try to open the contract manager UI\
**Then** I cannot open the contract manager UI
