# 7.2 - A Provider verifies the request for a usage contract offer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/72-provider-verifies-request-usage-contract-offer](https://simpl-programme.ec.europa.eu/book-page/72-provider-verifies-request-usage-contract-offer)

## Description

Simpl-Open shall support the Provider to automatically:

- Verify whether the Consumer complies with access policies as defined in the resource description.
- Verify if the Consumer has an existing usage contract for the resource description they are requesting.

## Detailed Requirements

- **7.2.1 – A Provider verifies the access policies** — Simpl-Open shall support the Provider to automatically verify access policies. [Details](https://simpl-programme.ec.europa.eu/book-page/721-provider-verifies-access-policies)
- **7.2.2 – A Provider verifies existence of a usage contract** — Simpl-Open shall support the Provider to automatically verify existing usage contracts. [Details](https://simpl-programme.ec.europa.eu/book-page/722-provider-verifies-existence-usage-contract)
