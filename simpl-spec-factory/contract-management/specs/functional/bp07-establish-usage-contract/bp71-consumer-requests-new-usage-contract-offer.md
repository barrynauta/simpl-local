# 7.1 - A Consumer requests a new usage contract offer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/71-consumer-requests-new-usage-contract-offer](https://simpl-programme.ec.europa.eu/book-page/71-consumer-requests-new-usage-contract-offer)

## Description

Simpl-Open shall support the Consumer to request a usage contract offer.

## Detailed Requirements

- **7.1.1 – A Consumer initiates the request for a usage contract offer** — Simpl-Open shall support the Consumer via UI and API to initiate a usage contract offer request. [Details](https://simpl-programme.ec.europa.eu/book-page/711-consumer-initiates-request-usage-contract-offer)
