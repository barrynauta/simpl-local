# 7.4 - A Consumer reviews the usage contract offer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/74-consumer-reviews-usage-contract-offer](https://simpl-programme.ec.europa.eu/book-page/74-consumer-reviews-usage-contract-offer)

## Description

Simpl-Open shall support the Consumer to:

- Review the details of the usage contract offer.
- Notify the Provider if the Consumer does not accept the usage contract offer.

## Detailed Requirements

- **7.4.1 – A Consumer reviews the usage contract offer** — Simpl-Open shall support the Consumer via UI and API to review the usage contract offer. [Details](https://simpl-programme.ec.europa.eu/book-page/741-consumer-reviews-usage-contract-offer)
- **7.4.2 – A Consumer notifies the Provider about the rejection of the usage contract offer** — Simpl-Open shall support the Consumer to automatically notify the Provider about a rejection. [Details](https://simpl-programme.ec.europa.eu/book-page/742-consumer-notifies-provider-about-rejection-usage-contract-offer)
