# 7.3 - A Provider creates and provides the usage contract offer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/73-provider-creates-and-provides-usage-contract-offer](https://simpl-programme.ec.europa.eu/book-page/73-provider-creates-and-provides-usage-contract-offer)

## Description

Simpl-Open shall support the Provider to automatically:

- Create a usage contract offer.
- Provide the usage contract offer to the Consumer.

## Detailed Requirements

- **7.3.1 – A Provider creates the usage contract offer** — Simpl-Open shall support the Provider to automatically create the usage contract offer. [Details](https://simpl-programme.ec.europa.eu/book-page/731-provider-creates-usage-contract-offer)
- **7.3.2 – A Provider provides the usage contract offer to a Consumer** — Simpl-Open shall support the Provider to automatically provide the usage contract offer to a Consumer. [Details](https://simpl-programme.ec.europa.eu/book-page/732-provider-provides-usage-contract-offer-consumer)
