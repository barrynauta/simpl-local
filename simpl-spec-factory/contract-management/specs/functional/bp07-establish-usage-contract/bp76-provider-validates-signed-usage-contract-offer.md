# 7.6 - A Provider validates the signed usage contract offer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/76-provider-validates-signed-usage-contract-offer](https://simpl-programme.ec.europa.eu/book-page/76-provider-validates-signed-usage-contract-offer)

## Description

Simpl-Open shall support the Provider to verify if the usage contract offer is signed by the Consumer.

## Detailed Requirements

- **7.6.1 – A Provider validates the signed usage contract offer** — Simpl-Open shall support the Provider via UI and API to validate the signed usage contract offer. [Details](https://simpl-programme.ec.europa.eu/book-page/761-provider-validates-signed-usage-contract-offer)
