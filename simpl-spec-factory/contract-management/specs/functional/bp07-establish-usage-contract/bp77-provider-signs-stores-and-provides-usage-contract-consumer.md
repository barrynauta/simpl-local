# 7.7 - A Provider signs, stores and provides the usage contract to the Consumer

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/77-provider-signs-stores-and-provides-usage-contract-consumer](https://simpl-programme.ec.europa.eu/book-page/77-provider-signs-stores-and-provides-usage-contract-consumer)

## Description

Simpl-Open shall support the Provider to:

- Sign the usage contract offer.
- Store the signed usage contract.
- Provide the finalised usage contract to the Consumer.

## Detailed Requirements

- **7.7.1 – A Provider signs the usage contract offer** — Simpl-Open shall support the Provider via UI and API to sign the usage contract offer. [Details](https://simpl-programme.ec.europa.eu/book-page/771-provider-signs-usage-contract-offer)
- **7.7.2 – A Provider stores the signed usage contract** — Simpl-Open shall support the Provider to automatically store the signed usage contract. [Details](https://simpl-programme.ec.europa.eu/book-page/772-provider-stores-signed-usage-contract)
- **7.7.3 – A Provider provides the signed usage contract to a Consumer** — Simpl-Open shall support the Provider to automatically provide the signed contract to the Consumer. [Details](https://simpl-programme.ec.europa.eu/book-page/773-provider-provides-signed-usage-contract-consumer)
