## UI run (step 60)

`./run.sh ui` runs the @ui scenarios in Chromium with Playwright for Python: 49 scenarios once outlines are expanded, 0 of them @manual. Every scenario opens a new browser context (no cookies, no storage, no stored sign-in) and signs in through the Keycloak form of realm E1. Report: `reports/ui.json` (behave JSON); axe results: `reports/a11y.json`; a screenshot per failed scenario: `reports/ui-artifacts/`.

Elements are found only by decided texts, labels, column headers, routes and ARIA roles (D60, D72, D74, D75, D90, D100, D109, D114, D115). No test id, CSS class, element id or generated name of the build is used. These generic interactions are assumptions, as no decision names them:

- A filter is applied by pressing Enter in a filter field (the Vocabulary status choice is applied with Enter in Name contains). A build that needs its own apply button would fail the filter scenarios.
- A field error is the field's accessible description (aria-describedby) plus aria-invalid, or else the extra text in the field's own container.
- A sortable column header holds a button or carries aria-sort; a trailing arrow glyph in a header is a sort indicator, not part of its name.
- A version row is selected by a click on the control in its first cell, or on the cell itself.
- 'Required' (D33) is checked as markup (required or aria-required) or else as behaviour: Submit with the field empty shows an error under it and sends no write.
- API stubs (D24) intercept browser requests whose path ends in `/v1<path>` (E2) and answer application/problem+json with the given status and detail.

### Test-writer fixes made while running against the build

- Waits used time.sleep, which stops Playwright from delivering events, so downloads were never seen; waits now use the page's own timer.
- Column header texts carry a sort arrow on the active column; the arrow is stripped before comparing headers.
- Selecting a version row clicked the cell centre and missed its control; the step now clicks the control in the first cell.
- 'Change log is required' first demanded a required attribute that no decision names; it now accepts the decided behaviour (D33, D62).
