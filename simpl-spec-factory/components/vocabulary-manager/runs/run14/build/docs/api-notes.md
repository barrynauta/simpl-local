# API notes

The published contract is `input/specs/api/vocabulary_openapi-tier1.yaml`. The build implements the decided
contract `docs/openapi-decided.yaml` (D79, D87), generated by `scripts/make_decided_openapi.py`. The backend test
`ContractTest` fails when the operation table, the Spring MVC handlers, the proxy's Allow map and the decided
contract differ (D93, D206).

## Base and media types

* Base URL `http://localhost:8196/v1`; `href` and `Location` are relative to it (E2).
* JSON success bodies are `application/json`; every error is `application/problem+json` (RFC 9457 with the Belgif
  `issues` extension). Downloads are exactly `text/turtle` with `Content-Disposition: attachment` (D29, D70).
* Every response carries `X-Correlation-Id` (taken from the request when it is safe, else generated) and the W3C
  trace context is read from `traceparent` (D86).

## Order of checks

Before routing: unknown method 405; firewall 400 (encoded slash, backslash, `;`, `//`, dot segments, control
characters); declared path with an undeclared method 405 with `Allow` (also HEAD, OPTIONS, TRACE, D126, D139);
unknown path 401 without token, 404 with one (D67). Then 401, 403, 406, 415, 413 by Content-Length, upload slot 503
(writes with files, D170), 413 for a file part over 5 MB, 400 (path, query, unknown or repeated fields, field rules,
version field), 404, 409, content validation (D51, D162, D169).

## Problem types (D48)

| Status | type |
|---|---|
| 400 | `urn:problem-type:belgif:badRequest` (issues: `...input-validation:schemaViolation` for request values, `...invalidInput` for content) |
| 401 | `urn:problem-type:simpl:unauthorized` |
| 403 | `urn:problem-type:simpl:forbidden` |
| 404 | `urn:problem-type:belgif:resourceNotFound` |
| 405 | `urn:problem-type:simpl:methodNotAllowed` |
| 406 | `urn:problem-type:simpl:notAcceptable` |
| 409 | `urn:problem-type:simpl:conflict` |
| 413 | `urn:problem-type:simpl:payloadTooLarge` |
| 414, 431 | `urn:problem-type:simpl:uriTooLong`, `urn:problem-type:simpl:requestHeaderFieldsTooLarge` |
| 415 | `urn:problem-type:simpl:unsupportedMediaType` |
| 500 | `urn:problem-type:belgif:internalServerError` |
| 503 | `urn:problem-type:belgif:serviceUnavailable`, header `Retry-After: 5` |

## Limits (Q2)

File part 5 MB; multipart request 6 MB (proxy 7 MB); JSON body 1 MB; at most 64 parts; pageSize 1 to 100;
integers 1 to 2147483647; name 3 to 64 characters `^[A-Z][a-zA-Z0-9]*$`; description and changelog 1 to 1000
characters after trimming; internal search 1 to 100 items; external search at most 100 URIs; at most 20 aliasUris;
validation report at most 1000 issues (`truncated: true`); 4 uploads at a time per instance; write budget 30 s.

## Health and metrics

`GET /v1/health` (no token): `UP`, `DEGRADED` (no realm keys cached and the last fetch failed) or `DOWN` with 503
when the store does not answer within 2 s. Container probes use `/actuator/health/liveness` on port 8081;
`/actuator/prometheus` on 8081 has `vocabulary_api_requests_seconds` (per operation and status),
`http_server_requests`, and `resilience4j_circuitbreaker_*` (D86, D103). Read them from inside the stack:
`docker compose exec backend wget -qO- http://localhost:8081/actuator/prometheus`.
