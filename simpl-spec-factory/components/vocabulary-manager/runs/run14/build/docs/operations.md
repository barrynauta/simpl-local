# Operations

## Backup and restore (Q3, D89, D156)

* `scripts/backup.sh`: dumps all named graphs as N-Quads through the store admin user from inside the store
  network, writes `backups/vocabulary-<UTC stamp>.nq.gz` with `.count` (quads) and `.sha256`, and copies the three
  files to `BACKUP_COPY_TARGET` (a mounted path or `user@host:/path` for scp) outside the host.
* `scripts/restore.sh <file>`: checks the checksum, stops the backends, loads the backup into a new TDB2 dataset,
  counts its quads, and only when the count equals the backup count swaps the new dataset in (the previous one is
  kept as `vocabulary-before-<stamp>` in the volume). Then starts store and backends and waits for the API.
  Writes after the backup are lost; that is inside the RPO of 24 h.
* `scripts/backup-restore-test.sh`: the round trip run on every build.
* `scripts/compact.sh`: online TDB2 compaction (`/$/compact/vocabulary?deleteOld=true`) and removal of receipts
  older than one hour. Run weekly after the backup.
* Example schedule: `scripts/cronjobs.example`. Installing the schedule is an operations task.

## Configuration (environment)

| Variable | Default | Meaning |
|---|---|---|
| VOCABULARY_CONTENT_BASE_URL | https://authority.example/vocabulary-manager | contentBase of E2 |
| STORE_URL, STORE_DATASET | http://fuseki:3030, vocabulary | store |
| STORE_READ_USER/PASSWORD, STORE_UPDATE_USER/PASSWORD | from .env | store users (D83) |
| ISSUER_URI | http://localhost:8193/realms/simpl | the one accepted issuer (E5) |
| JWKS_URL | http://keycloak:8080/realms/simpl/protocol/openid-connect/certs | realm keys |
| TOKEN_AUDIENCE | vocabulary-manager-be | required audience |
| UPLOAD_SLOTS | 4 | parallel uploads per instance (D92) |
| BACKEND_REPLICAS, BACKEND_CPUS, BACKEND_MEMORY, FUSEKI_*, KEYCLOAK_*, PROXY_* | D202 values | compose limits (D98) |

Secrets come from `.env` locally (generated by `stack.sh`, never committed) and from OpenBao in production (E6).

## Logs

JSON lines (Spring Boot structured logging, logstash format) with `traceId`, `spanId`, `correlationId`,
`operationId`, `vocabularyName`, `version` and `userId` (token subject only, D80, D96). Fuseki logs the request
line without query or update text; nginx logs method, path without query, status and time (D173).
