# API notes

The published contract (`../input/specs/api/vocabulary_openapi-tier1.yaml`) is unchanged (D39). The build
implements the decided contract, `openapi-decided.yaml`, generated by `tools/make_decided_openapi.py`.

## Order of checks

1. 405 for a method the path does not declare, or an unknown method (route filter, before security, D67, D77).
2. 400 for paths the firewall refuses (encoded slash, control characters), problem `belgif:badRequest`, no issues.
3. 401 without or with an invalid token, 503 when the realm keys cannot be fetched (D17, D44, D88).
4. 403 without the role of the operation (D16).
5. 406 Accept (D63), 415 Content-Type (D15), 413 size (D15, D76).
6. 400 request shape: path values, query parameters (unknown, repeated, invalid), unknown fields, field rules,
   the `version` field (D7, D21, D37, D49, D52, D91). All shape issues of one request come in one response.
7. 404, then 409, then content validation (D51).

## Problem types (D48)

| Status | Type |
|---|---|
| 400 | `urn:problem-type:belgif:badRequest`; issues `belgif:input-validation:schemaViolation` (request) or `invalidInput` (content) |
| 401 | `urn:problem-type:simpl:unauthorized` |
| 403 | `urn:problem-type:simpl:forbidden` |
| 404 | `urn:problem-type:belgif:resourceNotFound` |
| 405 | `urn:problem-type:simpl:methodNotAllowed` (free per D55) |
| 406 | `urn:problem-type:simpl:notAcceptable` |
| 409 | `urn:problem-type:simpl:conflict` |
| 413 | `urn:problem-type:simpl:payloadTooLarge` |
| 415 | `urn:problem-type:simpl:unsupportedMediaType` |
| 500 | `urn:problem-type:belgif:internalServerError` |
| 503 | `urn:problem-type:belgif:serviceUnavailable`, header `Retry-After: 5` |

## Choices where the decisions leave room

- Paging links: `page` and `pageSize` come first, then the other request parameters in request order (D78).
- Issue name for a bad element of `namespaceUris` or `aliasUris` in a search: the array name (D73 "the field").
- `aliasUris` in responses is always present, an empty array when there are none.
- The 201 of a create or new version also carries `createdBy` and `latestVersionHref` (equal to its own href).
- A 0-byte `vocabularyFile` passes the shape check and fails S6 (D70); a missing `vocabularyFile` is a shape error.
- A JSON body over 1 MB gives 413 with the simpl payloadTooLarge type.
- Accept: any media range that includes `application/json` or `application/problem+json` (for downloads
  `text/turtle`), including `application/*`, is accepted; q=0 ranges are ignored.
- Date-time filters without an offset are read as UTC.
- `GET /health` also applies the Accept and unknown-parameter checks.

## Security in front of the service

In production the Tier 1 gateway checks tokens and roles first (D17) and applies the call-rate limit (D46). The
service checks issuer, audience, signature and expiry itself, with keys of the realm only.
