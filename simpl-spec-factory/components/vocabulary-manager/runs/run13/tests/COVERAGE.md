## UI run (step 60)

`./run.sh ui` runs every @ui scenario in headless Chromium with Playwright for Python and writes behave JSON to `reports/ui.json`. Each scenario opens a new browser context: no stored session, cookies or storage. A failed UI step leaves its URL and accessibility tree in `reports/ui-failures/`.

@manual scenarios: none. Every @ui scenario could be automated with the roles, labels and texts of the decisions (D18, D23, D35, D60, D72, D75, D90, D109, D114, D115, D118, D141, D163) and the decided routes (D31, D74, D163) and API base path (E2).

Assumptions of the UI steps (no decision fixes these; they use no build detail):

- Sign-in uses the stock Keycloak login form of the decided identity provider (E1): 'Username or email', 'Password', 'Sign In'.
- An action a scenario calls a button may be a button or a link: the decisions fix the labels, not the roles ('New Vocabulary +' is a link in run 13).
- Menu items (D72) are found by role menuitem, or else by their exact visible text.
- A field error (D37, D62, D76, D101) is marked with aria-invalid="true"; a given error text is read through aria-describedby or aria-errormessage, or else as visible text.
- 'No request was sent to the API' means no POST, PUT, PATCH or DELETE to the API base path /v1.
- Route stubs (D24) match the decided API base path /v1 plus the scenario's path and answer application/problem+json. The 101-version stub copies the wire format from the real first page.
- A row a scenario does not filter for is looked up by following 'Next page' (D115), because the store is never reset (E4).
- 'I see the text' and 'I do not see the text' match the text as a whole phrase, case-sensitive, so 'Deprecate' does not match 'Deprecated'.

Result against run 13 (21 Nov 2026, two full runs in a row): 59 of 59 UI cases pass; axe reports 0 violations on the four main pages; every list action is reachable by Tab. No difference between the build and the specs or decisions was found in the UI.

They now check the region 'Version 1' (D64 is about the version shown). Tags unchanged.
