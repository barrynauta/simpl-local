## Behaviour worth knowing

- Every error is `application/problem+json`. Validation reports are 400 with one issue per error, `in: body`, `name: vocabularyFile` and a `location`; at most 1000 issues, then `"truncated": true` (D125).
- 201 responses carry `Location`, `createdBy`, `latestVersionHref` and `validationWarnings` (always present).
- Lists: `page` 1 to 2147483647, `pageSize` 1 to 100 (default 20). Links keep every request parameter, with page and pageSize first (D78, D110, D111). Beyond the last page: empty items, prev points to the last page (D59).
- Name filter is a case-insensitive contains match with `^[A-Za-z0-9]+$` (D19). Date filters accept a date (whole UTC day) or a date-time (to the second; no offset means UTC) (D20, D130).
- Searches are not paged: page 1, pageSize 100, total, totalPages 1 or 0, no links (D38, D153).
- Paths match names exactly (D54); uniqueness on create is case-insensitive (D37).
- Downloads: `Content-Type: text/turtle` without charset, `Content-Disposition: attachment; filename="<Name>.ttl"` or `"<Name>-v<n>.ttl"`; bytes exactly as uploaded.
- 503 with `Retry-After: 5` when the store or the identity provider is not available, when the circuit breaker is open, when a conditional write cannot complete within 30 s, or with more than 4 parallel uploads on one replica.
- Response headers on every answer: `X-Correlation-Id`, `Vary: Accept`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'`.

## Decided changes against the published contract

See D79 and the generated file. Stricter: 401, 403, 503 on secured operations; pageSize at most 100; field limits; unknown fields, unknown or repeated parameters rejected; version field rejected; search sizes; at most 20 aliases; absolute URIs; non-empty valid Turtle; invalid path values 400; 406; 405 on undeclared methods; multipart request at most 6 MB; JSON body at most 1 MB. Wider: relaxed name filter, `createdBy` and `latestVersionHref` on versions, `validationWarnings` always present, `truncated` on problems.

A local Schemathesis run (4.33.4, seed 1, 30 examples) found no 5xx. On the published contract the only failures were decided changes (schema-valid requests rejected under D19, D20, D52, D91, D137, D9) and one schema-violating request accepted (`name=000`, allowed by the relaxed name filter of D19). On `openapi-decided.yaml` the only failures were 6 multipart and JSON cases with extra or invalid content (D9, D52, D130). See `BUILD-LOG.md`.
