# SIMPL-26105: Governance Authority – validating a schema’s syntax and ensuring UUID and Version default properties - improvement
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2026-04-08, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-26105 (collected 2026-10-28)

## Description and acceptance criteria

This is an improvement for validation of default properties of a schema (data/application/infrastructure - SIMPL-14703).

As new default properties are introduced into the schema as part of resource description versioning (UUID, Version, SIMPL-26100), the validation of default properties should be extended to include these new attributes.

The ticket focuses exclusively on the validation of new default properties and the their relevant syntax.\
--------

**As a** Governance Authority,\
**I want** to validate a schema by performing syntax checks and ensuring the presence of the UUID and Version default properties\
**So that** I can ensure the structural correctness of the schema and UUID and Version default properties are correctly applied.

Acceptance criteria:

Positive scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema,\
**When** Simpl validates the structural correctness of the schema

**And** Simpl verifies the presence of the UUID and Version default properties

**Then** Simpl creates the new schema.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new version of an existing schema,\
**When** Simpl validates the structural correctness of the schema

**And** Simpl verifies the presence of the UUID and Version default properties

**Then** Simpl creates the new version of the existing schema.

Negative scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema,

**When** Simpl does not validate the structural correctness of the schema

Or Simpl does not verify the presence of the UUID and Version default properties

**Then** Simpl does not create the new schema.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new version of an existing schema,

**When** Simpl does not validate the structural correctness of the schema

Or Simpl does not verify the presence of the UUID and Version default properties

**Then** Simpl does not create the new version of the schema.

Technical details:

Additional default Properties for ALL resource types are in this ticket: [https://jira.simplprogramme.eu/browse/SIMPL-26100](https://jira.simplprogramme.eu/browse/SIMPL-26100)

Default properties must be added to all schemas.
