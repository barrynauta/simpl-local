# SIMPL-14712: Governance Authority – notifying Providers about schema changes - new version of the schema
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-06-26, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14712 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to notify Providers about the publication of a new version of an existing schema via e-mail\
**So that** Providers can take action to align resource descriptions with the schema changes.

Acceptance criteria:

1. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I publish a new version of an existing schema successfully\
**Then** Simpl notifies Providers about the change including the description of change, schema identifier, version (if applicable), timestamp, and any relevant instructions or links for follow-up actions via an e-mail.

2. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I publish a new version of an existing schema

**And** publishing is not successful\
**Then** Simpl does not notify Providers about changes via an e-mail.

Negative scenario:

**Given** I am a Governance Authority user without a valid authentication token granting the `GA_SCHEMA_ADMIN` role

**When** I submit a new version of an existing schema

**Then** Simpl responds with a `403 Forbidden` HTTP status\
**And** Simpl does not notify Providers about a new version of the schema via an e-mail.

Technical Notes:\
- We want to provide the email to which to send these notifications via a configuration key within the service's values
