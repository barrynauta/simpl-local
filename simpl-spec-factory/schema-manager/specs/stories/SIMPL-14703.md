# SIMPL-14703: Governance Authority – validating a schema’s syntax and ensuring default properties
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-06-26, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14703 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to validate a schema by performing syntax checks and ensuring the presence of default properties\
**So that** I can ensure the structural correctness of the schema and Simpl’s default properties are correctly applied.

Acceptance criteria:

Positive scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema,\
**When** Simpl validates the structural correctness of the schema

**And** Simpl verifies the presence of the default properties

**Then** Simpl creates the new schema.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new version of an existing schema,\
**When** Simpl validates the structural correctness of the schema

**And** Simpl verifies the presence of the default properties

**Then** Simpl creates the new version of the existing schema.

Negative scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema,

**When** Simpl does not validate the structural correctness of the schema

Or Simpl does not verify the presence of the default properties

**Then** Simpl does not create the new schema.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new version of an existing schema,

**When** Simpl does not validate the structural correctness of the schema

Or Simpl does not verify the presence of the default properties

**Then** Simpl does not create the new version of the schema.
