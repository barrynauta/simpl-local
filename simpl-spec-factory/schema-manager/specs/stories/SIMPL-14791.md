# SIMPL-14791: Governance Authority – notifying Providers about schema changes - revoked schema
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-06-27, updated: 2026-09-28
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14791 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to notify Providers about the revocation of a schema,

**So that** Providers can take action with respect to resource descriptions based on the schema.

Acceptance criteria:

1. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I revoke a schema successfully\
**Then** Simpl notifies Providers about the revocation of the schema, including information about schema identifier, timestamp, and suggested follow-up actions.

2. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I revoke a schema

**And** the revocation is not successful\
**Then** Simpl does not notify Providers about the revocation of the schema, including information about schema identifier, timestamp, and suggested follow-up actions.

Technical Notes:\
- We want to provide the email to which to send these notifications via a configuration key within the service's values
