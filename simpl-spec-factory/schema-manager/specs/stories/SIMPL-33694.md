# SIMPL-33694: Governance Authority notifies Providers about schema changes only for RESOURCE schemas
- Status: PBI INTERNAL QA
- Type: Story
- Created: 2026-09-22, updated: 2026-10-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-33694 (collected 2026-10-28)

## Description and acceptance criteria

Notice: Provider notification is already implemented. This story documents the notification behavior for RESOURCE schemas only. SEARCH schemas are out of scope and must not trigger these Provider notifications, as they are not relevant for resource creation. This Story is only about adding this distinction to the notification logic.

## User story

**As a** Governance Authority,\
**I want** to notify all Providers when a RESOURCE schema is published, a new version of an existing RESOURCE schema is published, or a RESOURCE schema is revoked,\
**So that** Providers are aware of schema changes and can take any required action to align their resource descriptions with the applicable schema.

## Acceptance criteria

### 1. New schema published

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** the schema type is RESOURCE\
**When** I successfully publish a new RESOURCE schema\
**Then** Simpl-Open notifies all Providers about the new schema, with the name, title, version, description and resource type of the new schema

### 2. New schema version published

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** the schema type is RESOURCE\
**When** I successfully publish a new version of an existing RESOURCE schema\
**Then** Simpl-Open notifies all Providers about the schema change, including the description of change, schema identifier, version (if applicable), timestamp, and any relevant instructions or links for follow-up actions via an e-mail.

### 3. Schema revoked

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** the schema type is RESOURCE\
**When** I successfully revoke a RESOURCE schema\
**Then** Simpl-Open notifies all Providers about the revocation

### 4. Failed schema lifecycle operation

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** the schema type is RESOURCE\
**When** publishing a RESOURCE schema, publishing a new version of a RESOURCE schema, or revoking a RESOURCE schema is unsuccessful\
**Then** Simpl-Open does not notify Providers about the schema change, including information about schema identifier, timestamp, and suggested follow-up actions.

### 5. SEARCH schema change

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** the schema type is SEARCH\
**When** I successfully publish, update, version, or revoke a SEARCH schema\
**Then** Simpl-Open does not notify Providers about the schema change
