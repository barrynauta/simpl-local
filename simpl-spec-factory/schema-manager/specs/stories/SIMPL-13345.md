# SIMPL-13345: Governance Authority - retrieving metadata for all versions of a schema via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-05-15, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-13345 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,

**I want** to retrieve a list of all available versions for a specific schema via API,

**So that** I can review its entire version history, change logs, and metadata.

Acceptance Criteria:\
**Given** I am an API client with a valid authentication token granting the `GA_SCHEMA_VIEWER or GA_SCHEMA_ADMIN` role.

**And** I have the unique name of an existing schema (e.g., `InfrastructureSchema`).

**When** I send a `GET` request to the `/schemas/{schemaName}/versions` endpoint.

**Then** the service shall respond with a `200 OK` HTTP status.

**And** the response body must be a paginated list of schema versions (20 items/page by default - see pagination guidelines [https://www.belgif.be/specification/rest/api-guide/#pagination])\
**And** each schema version in the list must include all its metadata

Negative Scenarios:\
**Given** I am an API client with a valid and authorized token.

**When** I send a `GET` request to `/schemas/{schemaName}/versions` where {schemaName} contains illegal characters (e.g., `Infrastructure$chema!`). (Schema name must be `PascalCase`. Alphanumeric only. Min 3, Max 64 chars. No spaces or special characters.)

**Then** the service shall respond with a `400 Bad Request` HTTP status.

**And** the response body should contain a descriptive error message about the invalid format.

—\
**Given** I am an API client with a valid authentication token granting the `GA_SCHEMA_VIEWER` role.

**And** I have a schema name that is correctly formatted but does not exist in the system (e.g., "UnknownSchema").

**When** I send a `GET` request to the `/schemas/UnknownSchema/versions` endpoint.

**Then** the service shall respond with a `404 Not Found` HTTP status.
