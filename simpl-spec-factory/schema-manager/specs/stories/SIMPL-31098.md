# SIMPL-31098: Governance Authority - publishing a validated federated search schema

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to publish a validated federated search schema\
**So that** the schema can be discovered and used by federated search services

Acceptance criteria:\
**Given** I am an authenticated Governance Authority user that has the `GA_SCHEMA_ADMIN` role,\
**When** no federated search schema exist\
**And** I create a new schema using the endpoint `POST /schemas` with `schemaType="SEARCH", a schema name, a title, and a shacl definition`\
**And** no resourceType specified\
**Then** Simpl shall respond with a `201 Created` response from the API and automatically publish this new created schema.

**Given** I am an authenticated Governance Authority user that has the `GA_SCHEMA_ADMIN` role,\
**When** there exists one federated search schema with schema name "FedSearch"\
**And** I publish this federated search schema with the endpoint `PATCH /schemas/FedSearch` with body "PUBLISHED"{{}}{}\
**Then** Simpl shall respond with a `201 Created` response from the API.

negative case:\
**Given** I am an authenticated Governance Authority user with a user account that has the `GA_SCHEMA_ADMIN` role,\
**When** there is already a federated search schema defined\
**And** I want to create another one using the endpoint `POST /schemas` with `schemaType="SEARCH", another schema name, a title, and a shacl definition`\
**And** no resourceType specified\
**Then** Simpl shall respond with an error (`409 Conflict`) stating there is already one federated search schema defined.

Validation hints:

checking whether a schema is published or revoked can be validated using the GET /schemas/{schemaName} endpoint with optional using a filter schemaType. In the resultset of this query the status field contains either "PUBLISHED" or "REVOKED"

Technical Details:

Ensure all tasks implemented for [https://jira.simplprogramme.eu/browse/SIMPL-29227] are still fully functional. Especially ensure all test cases consider the new introduces attribute schemaType for Schema Management API by setting this attribute explicitely to value for Federated Search Schema:\
- use updated Schema-Management API with new attribute schemaType (see [API-Definition impl-30422l](https://jira.simplprogramme.eu/browse/SIMPL-30422))\
- check all test cases\
- According to ADR-008 there is only one federated search schema, i.e. one schema with schemaType="SEARCH"
