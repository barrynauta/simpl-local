# SIMPL-24172: [UI] Governance Authority – displaying an error message when submitting a syntactically invalid schema
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2026-02-18, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-24172 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to get an error message via the UI when I submit a syntactically invalid schema or a syntactically invalid new version of an existing schema\
**So that** I can act and correct the syntax of the schema.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a syntactically invalid new schema via the UI

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a syntactically invalid new version of an existing schema via the UI

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

Negative scenario:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit syntactically valid new schema via the UI\
**Then** Simpl does not provide an error message about schema validation failure and reason.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a syntactically valid new version of an existing schema via the UI\
**Then** Simpl does not provide an error message about schema validation failure and reason.
