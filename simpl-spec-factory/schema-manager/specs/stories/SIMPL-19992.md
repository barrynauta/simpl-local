# SIMPL-19992: API for Subscription Management of Publishing Events
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-10-27, updated: 2026-06-05
- Source: https://jira.simplprogramme.eu/browse/SIMPL-19992 (collected 2026-10-28)

## Description and acceptance criteria

**As a** governance authority service,

**I want** to be able to subscribe to event notifications for a schema's status changes

**So that** I can ensure my service is always using the correct schema

## Acceptance Criteria

### Positive Scenarios

**Given** I have a valid endpoint ` [https://api.governance.com/listen](https://api.governance.com/listen)`

**When** I request to subscribe to the following events: `SchemaPublished`, `SchemaRevoked`

**Then** the system validates the endpoint URL

**And** the subscription is created successfully

**And** the system returns a HTTP 201 response

**And** the response payload contains a unique `webhookId`

**Given** a subscription exists for my service with ID (example): `webhook_id`

**When** I request a list of all active webhook subscriptions

**Then** the system returns a HTTP 200 response

**And** the list includes the subscription with ID `webhook_id`

**Given** a subscription exists with ID `wh_123`

**When** I request to delete the subscription with ID `wh_123`

**Then** the system removes the subscription

**And** the system returns a HTTP 204 or 200 success response

## Negative Scenarios

**When** I request to subscribe with targetUrl `not-a-url` (examples below)

**Then** the system rejects the request

**And** the system returns a HTTP 400 Bad Request error

**And** the error message indicates the URL is invalid

(Examples: `url`, `not-a-url`, `http://`,`[ftp://invalid.com](ftp://invalid.com/)` - the system should only accept standard http/https urls)

**When** I request to subscribe with a valid targetUrl

**But** I do not specify any event type

**Then** the system rejects the request

**And** the system returns a HTTP 400 Bad Request error indicating events are required

**When** I request to subscribe to the event `SchemaExploded`

**Then** the system rejects the request

**And** the system returns an error indicating `SchemaExploded` is not a valid event type

**Given** no subscription exists with ID `wh_999`

**When** I request to delete the subscription with ID `wh_999`

**Then** the system returns a HTTP 404 Not Found error
