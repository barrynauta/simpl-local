# SIMPL-22407: [API] Governance Authority – validating a schema’s semantics
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-12-15, updated: 2026-10-16
- Source: https://jira.simplprogramme.eu/browse/SIMPL-22407 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to validate schema semantics, including property validation rules, relationships, and dependencies\
**So that** schemas and schema versions are only created when their properties are semantically consistent with the referenced vocabularies.

Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema\
**When** Simpl validates the schema semantics\
**Then** Simpl verifies the validation rules, relationships, and dependencies for all properties in the schema\
**And** Simpl verifies that the schema properties are semantically consistent with the referenced vocabularies\
**And** Simpl creates the new schema\
**And** the API returns a success response with the created schema details

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** an existing schema exists\
**And** I submit a new version of the existing schema\
**When** Simpl validates the schema semantics\
**Then** Simpl verifies the validation rules, relationships, and dependencies for all properties in the schema\
**And** Simpl verifies that the schema properties are semantically consistent with the referenced vocabularies\
**And** Simpl creates the new version of the existing schema\
**And** the API returns a success response with the created schema version details

Negative scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** I submit a new schema\
**When** Simpl validates the schema semantics\
**And** one or more semantic validation checks fail\
**Then** Simpl does not create the new schema\
**And** the API returns a structured error response\
**And** the error response includes validation error details\
**And** each error includes, where applicable:\
* the affected schema property\
* the validation rule, relationship, or dependency that failed\
* the referenced vocabulary or vocabulary term involved\
* a human-readable error description

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**And** an existing schema exists\
**And** I submit a new version of the existing schema\
**When** Simpl validates the schema semantics\
**And** one or more semantic validation checks fail\
**Then** Simpl does not create the new schema version\
**And** the existing schema version remains unchanged\
**And** the API returns a structured error response\
**And** the error response includes validation error details\
**And** each error includes, where applicable:\
* the affected schema property\
* the validation rule, relationship, or dependency that failed\
* the referenced vocabulary or vocabulary term involved\
* a human-readable error description

Additional Notes:

Semantic validation is the overall validation process that ensures the schema is meaningful and consistent with the vocabularies it references. Validation rules, relationships, and dependencies are the specific checks performed as part of semantic validation:\
* checking that referenced vocabularies and vocabulary terms exist\
* checking that schema properties use allowed vocabulary terms\
* checking that property relationships are valid\
* checking that dependencies between properties are satisfied\
* checking that constraints defined by the referenced vocabularies are respected\
* we can only validate against self managed vocabularies as it wouldn't be safe to fetch external vocabularies\
* we issue warnings for external vocabularies that cannot be resolved\
* when doing semantic validation don't fail on first issue - perform a full semantic validation and return all semantic errors

Enforcement of validation rules, relationships, and dependencies is part of semantic validation.
