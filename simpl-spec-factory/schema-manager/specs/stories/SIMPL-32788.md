# SIMPL-32788: [ENHANCE] - Governance Authority - retrieving the contents of the latest version of a schema via API
- Status: PBI INTERNAL QA
- Type: Story
- Created: 2026-09-08, updated: 2026-10-23
- Source: https://jira.simplprogramme.eu/browse/SIMPL-32788 (collected 2026-10-28)

## Description and acceptance criteria

**As a** : User

**I want** to: Retrieve the raw SHACL content of the latest published version of a schema by making a request to a stable, unversioned URI so that I can review that version of the schema and consider further actions.

### Acceptance Criteria:

**Path: no optional schema type specified**\
**Given** I am an authenticated GA user,\
**And** a schema concept (e.g., ApplicationAsset) exists in the system.\
**And** the schemaType = RESOURCE\
**And** the ApplicationAsset schema has a version (e.g., "1.0.0", "1.1.0", "1.2.0"), with "1.2.0" being the latest.\
**When** I send a GET request to the endpoint for the schema concept, for example, [/schemas/ApplicationAsset](https://api.simpl.space/schemas/ApplicationAsset).\
**And** I do not set filter schemaType\
**Then** the service shall identify "1.2.0" as the latest version.\
**And** the service shall respond directly with a 200 OK HTTP status.\
**And** the response shall include a Content-Location header that specifies the versioned URI of the content being served (e.g., Content-Location: [/schemas/ApplicationAsset/1.2.0](https://api.simpl.space/schemas/ApplicationAsset/1.2.0]), which is also the named graph of the schema.\
**And** the response shall have a Content-Type header of text/turtle.\
**And** the body of the response shall contain the complete, raw SHACL content of version "1.2.0".

**Path: specified schema type = RESOURCE**\
**Given** I am an authenticated GA user,\
**And** a schema concept (e.g., ApplicationAsset) exists in the system.\
**And** the schemaType = RESOURCE\
**And** the ApplicationAsset schema has a version (e.g., "1.0.0", "1.1.0", "1.2.0"), with "1.2.0" being the latest.\
**When** I send a GET request to the endpoint for the schema concept, for example, [/schemas/ApplicationAsset](https://api.simpl.space/schemas/ApplicationAsset).\
**And** I set filter schemaType="RESOURCE"\
**Then** the service shall identify "1.2.0" as the latest version.\
**And** the service shall respond directly with a 200 OK HTTP status.\
**And** the response shall include a Content-Location header that specifies the versioned URI of the content being served (e.g., Content-Location: [/schemas/ApplicationAsset/1.2.0](https://api.simpl.space/schemas/ApplicationAsset/1.2.0]), which is also the named graph of the schema.\
**And** the response shall have a Content-Type header of text/turtle.\
**And** the body of the response shall contain the complete, raw SHACL content of version "1.2.0".

**Path: specified schema type = SEARCH**\
**Given** I am an authenticated GA user,\
**And** a schema concept (e.g., FederatedSearchAsset) exists in the system.\
**And** the schemaType = SEARCH\
**And** the FederatedSearchAsset schema has a version (e.g., "1.0.0", "1.1.0", "1.2.0"), with "1.2.0" being the latest.\
**When** I send a GET request to the endpoint for the schema concept, for example, [/schemas/ApplicationAsset](https://api.simpl.space/schemas/ApplicationAsset).\
**And** I set filter schemaType="SEARCH"\
**Then** the service shall identify "1.2.0" as the latest version.\
**And** the service shall respond directly with a 200 OK HTTP status.\
**And** the response shall include a Content-Location header that specifies the versioned URI of the content being served (e.g., Content-Location: [/schemas/FederatedSearchAsset/1.2.0](https://api.simpl.space/schemas/ApplicationAsset/1.2.0]), which is also the named graph of the schema.\
**And** the response shall have a Content-Type header of text/turtle.\
**And** the body of the response shall contain the complete, raw SHACL content of version "1.2.0".

### Negative Scenarios:\
**Given** I am an authenticated GA client,\
**When** I send a GET request to the Resolver Interface endpoint for a schema name that does not exist, such as [/schemas/NonExistentSchema](https://api.simpl.space/schemas/NonExistentSchema).\
**Then** the service shall respond with a 404 Not Found HTTP status.
