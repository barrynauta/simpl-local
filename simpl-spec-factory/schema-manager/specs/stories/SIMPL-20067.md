# SIMPL-20067: [UI] Governance Authority retrieving the contents of latest version of a schema via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-10-28, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-20067 (collected 2026-10-28)

## Description and acceptance criteria

Storycard\
||As|Governance Authority user|\
||I want|to retrieve the contents of the latest version of a specific schema via UI|\
||so that|I can review and edit the SHACL content of the latest version of the schema|

Acceptance criteria\
||Scenario||The Governance Authority retrieves the content of the latest schema on the UI||\
**Given** I am logged into the governance management portal with a user account that has the GA_SCHEMA_VIEWER or higher role\
**And** I retrieved the list of schemas and the list of schemas is displayed in the UI\
**When** I navigate to the list of actions for a specific schema\
**And** I click the download button of the specific schema\
**Then** UI calls GET /schemas/{schemaName} on my behalf\
**And** UI provides immediate feedback, downloading the raw SHACL content of the latest published schema version

Negative scenario: download error\
**Given** I am logged into the governance management portal with a user account that has the GA_SCHEMA_VIEWER or higher role\
**And** I retrieve the list of schemas and the list of schemas is displayed in the UI\
**When** I navigate to the list of actions for a specific schema\
**And** I click the download button of the specific schema\
**And** UI calls GET /schemas/{schemaName} on my behalf\
**And** API returns an error\
**Then** the UI remains on the form and displays a user-friendly message explaining the failure (e.g., "An error occurred while downloading the schema. Please update the page and try again.")

Technical details\
|Download button should be added as a first point in the actions list|\
|UI should use API GET endpoint to retrieve schemas metadata and version information\
API implemented in: [https://jira.simplprogramme.eu/browse/SIMPL-13347]|\
|UI should provide proper error messages for negative scenarios (above)|\
|The UI should adhere to the design principles: [https://confluence.simplprogramme.eu/pages/viewpage.action?pageId=48431839]|
