# SIMPL-13364: Governance Authority - retrieving details of a schema version via API
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-05-15, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-13364 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority User

**I want** to retrieve the content for a specific version of a schema via a version-specific API

**So that** I can review that version of the schema and consider further actions.

Acceptance Criteria

Positive Scenario:\
**Given** I am an authenticated Governance Authority user,\
**And** a specific version of a schema (e.g. 1.1.0) has been published,\
**When** I request the content of this specific version of the schema,\
**Then** Simpl shall answer with 200 OK HTTP status\
**And** provide the full schema content corresponding to version 1.1.0.

Negative Scenario 1:\
**Given** I am an authenticated Governance Authority user,\
**And** a specific version of a schema (e.g. 9.9.9) has not been published,\
**When** I request the content of this specific version of the schema,\
**Then** Simpl shall answer with 404 Not Found HTTP status\
**And** does not provide schema content.

Negative Scenario 2:\
**Given** I am an authenticated Governance Authority user,\
**And** a schema with a specific name has not been published,\
**When** I request the content of a version of this specific schema,\
**Then** Simpl shall answer with 404 Not Found HTTP status\
**And** does not provide schema content.

As this is not a REST API we don't need an API Definition task for it:\
* we don't need versioning (it's the schemas that are versioned)\
* we don't need any custom headers or request params that would involve having a REST API
