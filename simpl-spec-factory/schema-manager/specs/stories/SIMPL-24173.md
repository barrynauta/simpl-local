# SIMPL-24173: [UI] Governance Authority – receiving a notification about submitting an invalid schema - missing mandatory or default property
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2026-02-18, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-24173 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to display an error message via the UI when I submit a schema (not including default or mandatory property)\
**So that** I can act and correct the schema.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit an invalid schema (not including default or mandatory properties) via the UI

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit an valid schema via the UI\
**Then** Simpl does not provide an error message about schema validation failure and reason.
