## Description and acceptance criteria

**As a** Governance Authority User

**I want** to retrieve the content for a specific version of a schema via a version-specific API

**So that** I can review that version of the schema and consider further actions.

Acceptance Criteria

Positive Scenario:

Retrieve without optional filter. schemaType is default value "RESOURCE"\
**Given** I am an authenticated Governance Authority user,\
**And** a given schemaname\
**And** not specifying the optional schema type and resource type\
**And** a specific version of a schema (e.g. 1.1.0) has been created,\
**When** I request the content of this specific version of the schema,\
** with given schema name and version\
**Then** Simpl shall answer with 200 OK HTTP status\
**And** provide the schema meta datas corresponding to given schema name, schema type = RESOURCE and version (e.g. 1.1.0.)

Retrieve specific schema for schema-type RESOURCE and specified resource type\
**Given** I am an authenticated Governance Authority user,\
**And** a given schemaname\
**And** a given schema type (either RESOURCE or SEARCH)\
**And** a specific version of a schema (e.g. 1.1.0) has been created,\
**When** I request the content of this specific version of the schema,\
** with given schema name, schemaType and version\
**Then** Simpl shall answer with 200 OK HTTP status\
**And** provide the schema meta datas corresponding to given schema name, schema type and version (e.g. 1.1.0.)

Negative Scenario 1:\
**Given** I am an authenticated Governance Authority user,\
**And** a specific version of a schema (e.g. 9.9.9) has not been published,\
**When** I request the content of this specific version of the schema,\
**Then** Simpl shall answer with 404 Not Found HTTP status\
**And** does not provide schema content.

Negative Scenario 2:\
**Given** I am an authenticated Governance Authority user,\
**And** a schema with a specific name has not been published,\
**When** I request the content of a version of this specific schema,\
**Then** Simpl shall answer with 404 Not Found HTTP status\
**And** does not provide schema content.
