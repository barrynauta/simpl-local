## Description and acceptance criteria

**As a** Governance Authority,

**I want** to view all the versions of a specific schema on a dedicated page,

**So that** I can review their history, compare changes, and download specific versions.\
Acceptance Criteria:\
**Given** I am logged into the governance management portal with an authorized user account,\
**And** I have navigated to the details page for a specific schema (e.g., "Application resource schema") with given schemaType (default value RESOURCE)\
**When** the schema versions page loads,\
**Then** the UI shall call the backend `GET /schemas/\{schemaName}/versions` endpoint to retrieve all versions for that schema.\
**And** the UI shall display a table listing each version with its Version number, Status, SchemaType, ResourceType, Creation Date, Creator, and Latest Change (changelog).\
**And** the table shall be sortable by columns like Version and Creation Date.



Technical Documentation:\
- use backend GET /schemas/\{schemaName}/versions. Optional the filter schemaType=RESOURCE can be set.\
- enhance existing solution by adding new attribute schematype to distinguish RESOURCE for already implemented solution and "SEARCH" for Federated Search schemas. Ensure by explicitely setting filter for schemaType = RESOURCE for existing test cases they still work.\
