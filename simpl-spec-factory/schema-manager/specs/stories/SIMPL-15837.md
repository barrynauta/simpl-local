# SIMPL-15837: Governance Authority - retrieving a list of all schemas metadata and displaying them in UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-07-21, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-15837 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,

**I want** to view a paginated, sortable, and filterable list of all available schemas in the UI,

**So that** I can quickly find a specific schema and see its key properties like status, version, and creator at a glance.

## Acceptance Criteria\
**Given** I am logged into the schema management with a user account that has a role authorizing schema viewing (e.g., GA_SCHEMA_ADMIN or GA_SCHEMA_VIEWER),\
**And** I have navigated to the "Schemas list" page.\
**When** the schema list page loads,\
**Then** the UI shall call the backend GET /schemas endpoint to retrieve the first page of schemas.\
**And** the UI shall display a table of schema concepts, showing the Schema Name, Title, Description, Resource Type, Latest Version, Status, Creation Date, and Creator for each schema returned.\
**And** the list shall provide controls to sort by key columns like Schema Name and Title.\
**And** the list shall be paginated, with controls to navigate between pages.

**Given** I am an authorized user viewing the "Schemas list" page,\
**When** I use the filter controls to select a status (e.g., "PUBLISHED") or a resourceType (e.g., "application"),\
**Then** the UI shall re-call the GET /schemas endpoint with the appropriate query parameters.\
**And** the list of schemas shall update to show only the results matching the selected filters.

**Given** I am an authorized user viewing the list of schemas on the "Schemas list" page,\
**When** I click on the name of a schema in the list,\
**Then** I shall be navigated to the details page for that specific schema concept, where all its versions will be listed

Negative scenarios:\
**Given** I am logged into the schema management portal

**And** I have navigated to the "Schemas list" page

**When** the UI calls the backend `GET /schemas` endpoint and the call fails for any reason (e.g., a network error, a 5xx server error, or my session is expired)

- OR

**When** my user account does not have the required `GA_SCHEMA_ADMIN` or `GA_SCHEMA_VIEWER` role

**Then** the UI shall not display the schema list table or its controls (pagination, sorting, filtering).

**And** the UI shall display a clear, user-friendly error message (e.g., "Could not load schemas. Please try again later." or "You do not have permission to view this page.").

**And** the page should ideally provide a "Retry" or "Reload" option if the error was temporary.

---

**Given** I am an authorized user on the "Schemas list" page

**When** the backend returns an empty list of schemas on the initial page load

- OR

**When** I apply a combination of filters that results in zero matching schemas

**Then** the UI shall display the table headers (Schema Name, Title, etc.) but the table body will be empty.

**And** a clear message shall be displayed within the table area indicating that no results were found (e.g., "No schemas found." or "No schemas match the selected filters.").

**And** all pagination controls shall be disabled or hidden.
