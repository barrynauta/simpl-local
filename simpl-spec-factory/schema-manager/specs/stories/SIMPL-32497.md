# SIMPL-32497: [UI] Governance Authority – retaining revoked schema for referencing via UI
- Status: PBI for SC review
- Type: Story
- Created: 2026-09-03, updated: 2026-10-26
- Source: https://jira.simplprogramme.eu/browse/SIMPL-32497 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to retain a revoked schema,\
**So that** I can ensure that the existing resource descriptions still can reference it.

Acceptance criteria:

**Given** I am authenticated as a Governance Authority user, with a role authorising schema management and a resource description in my catalogue refers to a certain schema\
**When** I revoke that schema via the UI or the API\
**Then** the reference in the published resource description is still valid and retrievable.

**Given** I am authenticated as a Governance Authority user, with a role authorising schema management\
**When** I revoke the federated search schema via the UI or the API\
**Then** the federated search cross multiple trustor GA will be disabled

Technical Details:\
* use implemented API defined Simpl-30422 to explicitely reference schemaType\
* use admin dialogs specifying explicitely the schema type either RESOURCE for Resource Descriptions and SEARCH for Federated Search\
* For SEARCH Schema there is no retaining functionality. According to ADR-009 there is only one federated Search Schema possible. It there is no valid federated Search Schema published no federated Search cross multiple data spaces is possible.
