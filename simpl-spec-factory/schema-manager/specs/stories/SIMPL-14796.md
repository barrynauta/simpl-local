# SIMPL-14796: [API] Governance Authority – receiving an error message about submitting an invalid schema - missing mandatory or default property
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-06-27, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14796 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to receive an error message when I submit a schema not including default or mandatory properties\
**So that** I can act and add the missing mandatory and default properties.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit an invalid schema (not including default or mandatory properties)

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit an valid schema\
**Then** Simpl does not provide an error message about schema validation failure and reason.
