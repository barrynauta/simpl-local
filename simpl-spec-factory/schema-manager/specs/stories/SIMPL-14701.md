# SIMPL-14701: Governance Authority – retaining revoked schema for referencing where the schema was revoked via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-06-26, updated: 2026-07-30
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14701 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to retain a revoked schema,\
**So that** I can still refer to the schema using it's identifier

## Acceptance criteria:

**Given** [color:#172b4d]I am authenticated as a Governance Authority user, with a role authorising schema management [color]and a resource description in my catalogue refers to a certain schema\
**When** I revoke that schema via the UI\
**Then** the reference in the published resource description is still valid and retrievable.
