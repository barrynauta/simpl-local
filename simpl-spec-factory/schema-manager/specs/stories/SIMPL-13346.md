# SIMPL-13346: Governance Authority - retrieving metadata for all versions of a schema via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-05-15, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-13346 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,

**I want** to view all the versions of a specific schema on a dedicated page,

**So that** I can review their history, compare changes, and download specific versions.

## Acceptance Criteria:\
**Given** I am logged into the governance management portal with an authorized user account,

**And** I have navigated to the details page for a specific schema (e.g., "Application resource schema").

**When** the schema versions page loads,

**Then** the UI shall call the backend `GET /schemas/{schemaName}/versions` endpoint to retrieve all versions for that schema.

**And** the UI shall display a table listing each version with its **Version** number, *Status*, *Creation Date*, *Creator*, and **Latest Change** (changelog).

**And** the table shall be sortable by columns like **Version** and *Creation Date*.
