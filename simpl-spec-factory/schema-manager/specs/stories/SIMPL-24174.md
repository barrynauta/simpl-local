# SIMPL-24174: [UI] Governance Authority – semantic validation message after submitting a schema
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2026-02-18, updated: 2026-10-16
- Source: https://jira.simplprogramme.eu/browse/SIMPL-24174 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to receive an error message when I submit via the UI a new schema or a new version of an existing schema with invalid rules (semantic validation),\
**So that** I can act and correct the schema to comply its validation rules.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a new schema with invalid rules via the UI

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a new version of an existing schema with invalid rules via the UI

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

Negative scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a valid new schema via the UI

**Then** Simpl does not provide an error message about schema validation failure and reason.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a valid new version of an existing schema via the UI

**Then** Simpl does not provide an error message about schema validation failure and reason.
