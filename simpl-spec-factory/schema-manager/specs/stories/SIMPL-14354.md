# SIMPL-14354: Governance Authority – retaining revoked schema for referencing where the schema was revoked via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-06-17, updated: 2026-08-20
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14354 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to retain a revoked schema,\
**So that** I can still refer to the schema using it's identifier

## Acceptance criteria:

**Given** {color:#172b4d}I am authenticated as a Governance Authority user, with a role authorising schema management{color}

**And** a schema has been revoked\
**When** I retrieve, via API, that schema using its identifier\
**Then** the schema and its properties are returned

## Note:

The API behavior is already determined and set with the API definition story and the API implementation story for publish/revocation. This scenario covers an internal logic requirement that when a schema is revoked it's still persisted - it does not change the API behavior and data model that would need additional testing from that point of view
