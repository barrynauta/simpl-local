# SIMPL-17066: Resource Description Schema Management Access Control - Tier 1
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-08-14, updated: 2026-08-04
- Source: https://jira.simplprogramme.eu/browse/SIMPL-17066 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
[I want to](#) restrict all schema related actions (create a new schema, create a new version of a schema, publish a schema, revoke a schema, list schema details, list schema versions) to resource description schemas to authorised users,\
**So that** schema management processes remain secure, auditable, and compliant with established access control policies.

## Acceptance criteria:

---

**Given** I am authenticated as a Governance Authority user,

**And** I have the schema management role (GA_SCHEMA_ADMIN),\
**When** I attempt to perform a create a new schema action\
**Then** Simpl authorises creating a new schema action and allows to perform it.\
---

---

**Given** I am authenticated as a Governance Authority user,

**And** I have schema management role (GA_SCHEMA_ADMIN),\
**When** I attempt to perform a create a new version of a schema\
**Then** Simpl authorises creating a new version of a schema action and allows to perform it.\
---

---

**Given** I am authenticated as a Governance Authority user,

**And** I have the schema management role (GA_SCHEMA_ADMIN),\
**When** I attempt to perform a revoke a schema action\
**Then** Simpl authorises revoking a schema action and allows to perform it.\
---

---

**Given** I am authenticated as a Governance Authority user,

**And** I have the schema management role (GA_SCHEMA_ADMIN),\
**When** I attempt to perform a publish a schema action\
**Then** Simpl authorises publishing a schema action and allows to perform it.\
---

---

**Given** I am authenticated as a Governance Authority user,

**And** I have the schema viewer or schema management role (GA_SCHEMA_VIEWER or GA_SCHEMA_ADMIN),\
**When** I attempt to perform a list schema details action\
**Then** Simpl authorises listing the schema details action and allows to perform it.\
---

---

**Given** I am authenticated as a Governance Authority user,

**And** I have the schema viewer or schema management role (GA_SCHEMA_VIEWER or GA_SCHEMA_ADMIN),\
**When** I attempt to perform a list schema versions action\
**Then** Simpl authorises listing the schema versions action and allows to perform it.\
---

Technical Info:

* this is only Tier 1 authentication\
* roles are GA_SCHEMA_ADMIN for create a new schema, create a new version of a schema, publish a schema, revoke a schema, list schema details, list schema versions functionalities\
* roles are GA_SCHEMA_VIEWER for list schema details, list schema versions functions\
* GA_SCHEMA_ADMIN can do everything that GA_SCHEMA_VIEWER CAN DO
