# SIMPL-14795: [API] Governance Authority – receiving an error message when submitting a syntactically invalid schema
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-06-27, updated: 2026-09-22
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14795 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority administrator,\
**I want** to receive an error message when I submit a syntactically invalid schema\
**So that** I can act and correct the syntax of the schema.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority administrator\
**And** I have a role authorising schema management

**When** I submit a syntactically incorrect schema

**Then** Simpl returns with an error message about the syntax error.

**Given** I am authenticated as a Governance Authority administrator\
**And** I have a role authorising schema management

**When** I submit a syntactically correct schema

**Then** Simpl does not return with an error message about syntax error.

## Technical Info:\
- Errors from Syntax Validation should come under

```java\
{\
...\
detail: "Syntax Error: <errorMessage>"\
...\
}\
```\
