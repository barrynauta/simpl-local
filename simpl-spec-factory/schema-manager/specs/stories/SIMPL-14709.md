# SIMPL-14709: Governance Authority – notifying Providers about when publishing a new schema
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-06-26, updated: 2026-09-28
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14709 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to notify Providers when publishing a new schema\
**So that** Providers can take action to align resource descriptions with the schema changes.

## Acceptance criteria:

1. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I publish a new schema successfully\
**Then** Simpl notifies Providers with the name, title, version, description and resource type of the new schema

**And** the notification includes links for instructions how to use the new schema and follow-up actions.

2. Given I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management\
**When** I publish a new schema

**And** publishing is not successful\
**Then** Simpl does not notify Providers about unsuccessful publication.
