# SIMPL-24175: Resource Description Schema Management Access Control - Tier 2
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2026-02-18, updated: 2026-09-21
- Source: https://jira.simplprogramme.eu/browse/SIMPL-24175 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to restrict all actions related to schema management subscription,\
**So that** schema management subscription processes remain secure, auditable, and compliant with established access control policies.

## Acceptance criteria:

**Given** an authenticated Participant

**And** the Participant uses active and valid Tier2 credentials\
**When** that Participant submits a valid request for subscription to schema publishing events to the Governance Authority\
**Then** the Governance Authority verifies and confirms that the Participant uses the active and valid Tier2 credentials\
**And** the Governance authority handles the request

## Negative scenario:

**Given** an authenticated Participant

**And** the Participant does not use active and valid Tier2 credentials

**When** that Participant submits a valid request for subscription to schema publishing events to the Governance Authority

**Then** the Governance Authority detects that the Participant does not use active and valid Tier2 credentials

**And** the Governance authority does not handle the request

**Given** a Participant that is not authenticated

**When** that Participant submits a valid request for subscription to schema publishing events to the Governance Authority

**Then** the Governance Authority detects that the Participant is not authenticated

**And** the Governance authority does not handle the request

Technical Info:\
* this is only Tier 2 authentication\
* only for the webhook endpoints\
* no attribute check required - we only allow it via the T2 gateway but without ABAC - this enables all participants\
* service has no ingress so only communication is either from within the agent (e.g. Catalogue) or via T2 gateway (from outside)
