# SIMPL-14797: [API] Governance Authority – receiving an error message about submitting a schema not complying with its validation rules
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-06-27, updated: 2026-10-14
- Source: https://jira.simplprogramme.eu/browse/SIMPL-14797 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to receive an error message when I submit a new schema or a new version of an existing schema with invalid rules (semantic validation),\
**So that** I can act and correct the schema to comply its validation rules.

## Acceptance criteria:

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a new schema with invalid rules

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a new version of an existing schema with invalid rules

**Then** the schema validation fails

**And** Simpl provides an error message about the schema validation failure and the reason

Negative scenario

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a valid new schema

**Then** Simpl does not provide an error message about schema validation failure and reason.

**Given** I am authenticated as a Governance Authority user\
**And** I have a role authorising schema management

**When** I submit a valid new version of an existing schema

**Then** Simpl does not provide an error message about schema validation failure and reason.

## Technical Info:\
- Errors from Syntax Validation should come under

```java\
{\
...\
detail: "Semantic Validation Error: <errorMessage>"\
...\
}\
```
