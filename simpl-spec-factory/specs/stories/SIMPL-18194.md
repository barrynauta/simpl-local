# SIMPL-18194: Receive vocabulary validation report via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18194 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority,
I want the API to return a detailed validation report when I submit a vocabulary creation or new version creation request,
so that integrations can process validation feedback programmatically.

Acceptance Criteria
Given I am authenticated as a Governance Authority user
and I submit a vocabulary creation or new version creation request via the API
when the submitted vocabulary contains syntax or semantic errors
then the API response returns a structured report listing all errors with detailed descriptions and location

Given I am authenticated as a Governance Authority user
and I submit a vocabulary creation or new version creation request via the API
when the submitted vocabulary does not contain syntax or semantic errors
then the API confirms successful validation as part of the creation or version creation response without separate error details.
