# SIMPL-18166: Retrieve full details of a vocabulary version via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18166 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority
I want to retrieve the complete details of a specific vocabulary version via the API
so that I can inspect or reuse its structure programmatically

Acceptance Criteria
Positive Scenario - Existing vocabulary version is retrieved successfully
Given I am authenticated as a Governance Authority with API access and authorized for vocabulary management
And I have identified an existing vocabulary version
When I request full details for that vocabulary version
Then the API returns the complete structure and metadata in a machine-readable format

Negative Scenario - Requested vocabulary version does not exist
Given I am authenticated as a Governance Authority with API access and authorized for vocabulary management
When I request full details for a vocabulary version that does not exist
Then the API returns an error indicating that the requested vocabulary version could not be found

Note:

authorization and authentication are handled in https://jira.simplprogramme.eu/browse/SIMPL-16635
Endpoint would be: `/vocabularies/{vocabularyName}/versions/{version}`
