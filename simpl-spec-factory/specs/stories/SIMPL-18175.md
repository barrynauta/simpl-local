# SIMPL-18175: Update vocabulary status via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18175 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority\
**I want** to update a vocabulary status via the API\
**so that** I can manually set it to ACTIVE or DEPRECATED

Acceptance Criteria\
**Given** I am authenticated and authorised as a Governance Authority\
**When** I request a status change for a specific vocabulary via the API\
**Then** the API updates the vocabulary status to the requested value (ACTIVE or DEPRECATED)\
**And** responds with the updated vocabulary metadata

Negative Scenario - Requested vocabulary does not exist\
**Given** I am authenticated and authorised as a Governance Authority\
**And** the vocabulary I want to update does not exist\
**When** I request a status change for that vocabulary via the API\
**Then** the API returns an error indicating that the requested vocabulary could not be found

Negative Scenario - Requested vocabulary status is not supported\
**Given** I am authenticated and authorised as a Governance Authority\
**And** the vocabulary I want to update exists\
**When** I request a status change using a value other than `ACTIVE` or `DEPRECATED`\
**Then** the API rejects the request with a validation error\
**And** the vocabulary status remains unchanged
