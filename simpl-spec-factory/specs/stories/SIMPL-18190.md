# SIMPL-18190: Automatic versioning of vocabularies via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18190 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority,
I want to have the API automatically assign the next version identifier when I create a new version of an existing vocabulary,
so that version numbering remains consistent and traceable without manual input.

Acceptance Criteria
Given I am authenticated as a Governance Authority user with a role authorising vocabulary management
and the vocabulary I want to update exists
when I submit a new version request with updated content via the API
then the system automatically assigns the subsequent version number based on the applicable versioning algorithm as part of that request
and the API response confirms the assigned version number
and no manual version number is required in the request

Negative Scenario - Manual version number is provided in the request
Given I am authenticated as a Governance Authority user with a role authorising vocabulary management
And the vocabulary I want to update exists
When I submit a new version request via the API and include a manual version number
Then the API rejects the request because version numbers are assigned automatically
And no new version is created

Technical Info:

the versioning should be incremental using the same versioning library as schema management
