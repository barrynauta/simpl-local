# SIMPL-18452: Download and view full details of all vocabulary versions in the UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-16, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18452 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority
I want to download and view the complete details of a selected vocabulary version in the UI
so that I can review details before creating a new version

Acceptance Criteria

Given I am authenticated as a Governance Authority with permission to manage vocabularies
And I am on the Vocabulary Management page
When I open a vocabulary and select a specific version for review
Then I can access that selected version

Given I have selected a vocabulary version
When I click download
Then the system provides a file containing the full details of the selected version
