# SIMPL-18189: Automatic versioning of vocabularies via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18189 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority user,
I want to have the UI automatically assign the next version identifier when I create a new version of an existing vocabulary,
so that version numbering remains consistent and traceable without manual input.

Acceptance Criteria

AC1 – Automatic version assignment on successful creation
Given I am authenticated as a Governance Authority user with vocabulary management rights
And I am accessing an existing vocabulary in the UI
When I initiate the creation of a new version
And I submit the new vocabulary version
Then Simpl-Open automatically generates and assigns the next version identifier based on the versioning algorithm
And Simpl-Open stores this version together with the vocabulary

AC2 – No manual input required for versioning
Given I am creating a new version of a vocabulary
When I fill in and submit the form
Then I am not required to enter or modify the version identifier manually

AC3 – UI feedback on assigned version
Given a new version has been successfully created
When the operation completes
Then the UI displays a confirmation message including the newly assigned version identifier
