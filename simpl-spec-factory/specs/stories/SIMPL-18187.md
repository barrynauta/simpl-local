# SIMPL-18187: Publish vocabulary via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18187 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** validated vocabulary creation or version creation requests submitted via the API to be automatically persisted and made available\
**So that** no separate publish endpoint or workflow is required

### Acceptance Criteria

#### AC1 – Create New Vocabulary

**Given** a new vocabulary is submitted through the API\
**And** the vocabulary passes all validation rules\
**When** the API processes the request\
**Then** the vocabulary is persisted in the vocabulary repository\
**And** the API response confirms successful creation\
**And** the response includes an identifier indicating the vocabulary is available in the vocabulary registry

#### AC2 – Create New Vocabulary Version

**Given** an existing vocabulary\
**And** a new version of that vocabulary is submitted through the API\
**And** the new version passes all validation rules\
**When** the API processes the request\
**Then** the new version is persisted\
**And** the new version is linked to the existing vocabulary\
**And** the API response confirms successful creation of the new version\
**And** the response includes an identifier indicating the new version is available in the vocabulary registry

Technical Description / Notes:\
- this story is about persisting the Vocabulary to the persistance after validation - but we'll setup persistance from the start as part of API for creating a vocabulary and have validation in separate stories.\
- this does require testing!
