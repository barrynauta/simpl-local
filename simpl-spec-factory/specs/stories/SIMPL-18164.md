# SIMPL-18164: Apply filters and sorting via vocabulary list API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18164 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to apply sorting and filtering when retrieving vocabularies via the API\
**So that** I can focus on the records relevant to my needs

Acceptance Criteria\
- Positive Scenario - Filter and sort vocabularies using supported fields\
**Given** I am authenticated as a Governance Authority and have API access\
**When** I request vocabularies using supported filter and sort options on `name`, `status`, `creationDate` and `lastUpdated`\
**Then** I receive only vocabularies matching the requested filter criteria\
**And** the results are ordered according to the requested sort field and direction

- Positive Scenario - Filter returns no matching vocabularies\
**Given** I am authenticated as a Governance Authority and have API access\
**When** I request vocabularies using supported filter options and no vocabularies match the criteria\
**Then** the API returns an empty result set\
**And** the request is handled successfully without returning an error

- Positive Scenario - Pagination is applied together with sorting\
**Given** I am authenticated as a Governance Authority and have API access\
**When** I request a paginated vocabulary list using supported sort options on `name`, `status`, `creationDate` and `lastUpdated`\
**Then** the API returns only the requested page of results\
**And** the returned page preserves the requested sort order consistently

- Negative Scenario - Filter or sort parameters are not supported or invalid\
**Given** I am authenticated as a Governance Authority and have API access\
**When** I request vocabularies using an unsupported filter or sort field, or an invalid filter value\
**Then** the API rejects the request with a validation error\
**And** no filtered result set is returned
