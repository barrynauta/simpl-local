# SIMPL-18176: Access deprecated vocabulary versions in UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18176 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to access deprecated vocabulary versions in the UI\
**So that** I can review or audit historical versions and understand how they affect current resources

*Acceptance Criteria*

*AC1 – Authentication and authorization*\
**Given** I am an authenticated Governance Authority user\
**And** I have a role authorizing read access to the vocabulary history\
**When** I access the vocabulary management or history interface\
**Then** I am authorized to view vocabulary versions, including deprecated ones

*AC2 – Display deprecated versions*\
**Given** there are vocabulary versions marked as *DEPRECATED*\
**When** I search, filter, or browse vocabulary versions\
**Then** the system displays the deprecated versions\
**And** each deprecated version is clearly labeled as *DEPRECATED*

*AC3 – View metadata of deprecated versions*\
**Given** a deprecated vocabulary version is displayed\
**When** I select or open that version\
**Then** I can view all associated metadata (e.g., version identifier, creation date, creator, change summary)
