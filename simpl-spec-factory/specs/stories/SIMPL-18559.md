# SIMPL-18559: Warning on deprecated vocabulary versions in Vocabulary History UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-19, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18559 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority user,\
**I want** to see a warning when deprecated vocabulary versions are shown on the vocabulary history page\
**So that** I am discouraged from using them in future resources

### Acceptance Criteria

**AC1 – Warning and redirection to active version**\
**Given** I am an authenticated Governance Authority user with any role\
**And** a vocabulary version has status DEPRECATED\
**And** there is a more recent ACTIVE version for this vocabulary\
**When** I view it on the vocabulary history page\
**Then** Simpl-Open displays a clear warning message indicating that the version is deprecated\
**And** Simpl-Open provides a visible reference to the latest ACTIVE version

**AC2 – Warning displayed when no active version exists**\
**Given** I am an authenticated Governance Authority user with any role\
**And** a vocabulary version has status DEPRECATED\
**And** there is no ACTIVE version available for this vocabulary\
**When** I view it on the vocabulary history page\
**Then** Simpl-Open displays a clear warning message indicating that the version is deprecated
