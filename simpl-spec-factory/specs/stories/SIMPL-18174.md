# SIMPL-18174: Update vocabulary status via UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18174 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority\
**I want** to update a vocabulary status via the UI\
**So that** I can manually mark a vocabulary as DEPRECATED or restore it to ACTIVE

Acceptance Criteria\
**Given** I am authenticated and authorised as a Governance Authority\
**And** I am viewing a vocabulary management page\
**When** I select the status-change action for a vocabulary\
**And** I choose ACTIVE or DEPRECATED\
**Then** the system updates the vocabulary status accordingly\
**And** shows the updated status in the UI\
**And** displays a notification confirming the vocabulary status was successfully updated

Negative Scenario - Selected vocabulary is no longer available\
**Given** I am authenticated and authorised as a Governance Authority\
**And** I am viewing a vocabulary management page\
**When** I select the status-change action for a vocabulary that is no longer available\
**Then** the system informs me that the vocabulary could not be found\
**And** no status change is applied

Negative Scenario - Error occurs while updating the vocabulary status\
**Given** I am authenticated and authorised as a Governance Authority\
**And** I am viewing a vocabulary management page\
**When** I select the status-change action for a vocabulary and the update fails during processing\
**Then** the system informs me that the vocabulary status could not be updated\
**And** the vocabulary status remains unchanged in the UI
