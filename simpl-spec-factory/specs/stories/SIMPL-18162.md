# SIMPL-18162: Retrieve metadata of all vocabularies via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18162 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to retrieve the metadata of all vocabularies via the API\
**So that** I can use this data in external systems and reports

Acceptance Criteria\
|Scenario|The Governance Authority requests the metadata of each vocabularies - positive case|\
**Given** I am authenticated as a Governance Authority with a valid authentication token granting vocabulary management role\
**When** I request the metadata of all vocabularies via API\
**Then** Simpl-Open answers with success message 200 OK\
**And** the response body shall contain a paginated list of vocabularies\
**And** each resource in the list shall include all the relevant metadata (name, version, description, status, creationDate, lastUpdateDate)

|Scenario|The Governance Authority requests the metadata of each vocabularies - negative case: wrong pagination|\
**Given** I am authenticated as a Governance Authority with a valid authentication token granting vocabulary management role\
**And** I request the metadata of all vocabularies via API\
**And** I ask with wrong query parameter for pagination\
**Then** Simpl-Open answers with error message 400 Bad request\
**And** the response body shall contain the detail of the error\
**And** metadata shouldn't be returned

|Scenario|The Governance Authority requests the metadata of each vocabularies - negative case: forbidden user|\
**Given** I am authenticated as a Governance Authority with a valid authentication token and without vocabulary management role\
**And** I request the metadata of all vocabularies via API\
**Then** Simpl-Open answers with error message 403 Forbidden\
**And** the response body shall contain the detail of the error\
**And** metadata shouldn't be returned

|Scenario|The Governance Authority requests the metadata of each vocabularies - negative case: internal error|\
**Given** I am authenticated as a Governance Authority with a valid authentication token granting vocabulary management role\
**And** I request the metadata of all vocabularies via API\
**And** my the request is not processed bacause of an internal error\
**Then** Simpl-Open answers with error message 500 Internal error\
**And** the response body shall contain the detail of the error\
**And** metadata shouldn't be returned
