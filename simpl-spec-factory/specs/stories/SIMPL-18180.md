# SIMPL-18180: Validate vocabulary syntax and structure via UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18180 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority with vocabulary management permissions\
**I want** syntax and structure validation to run automatically when I upload or submit a vocabulary in the UI\
**So that** I ensure vocabularies conform to required formats before being stored

h2. *Scope Clarification*

This story covers *only syntax and structure validation* of vocabulary files.

The following aspects are *out of scope* and covered in separate stories:\
- Authentication and authorization failures\
- Metadata validation (e.g. required fields, naming rules)\
- Business validation rules beyond structure\
- Technical/system error handling

h2. *Acceptance Criteria*\
h3. *AC1 – Validation Trigger on File Upload*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**When** I upload a vocabulary file in the UI\
**Then** the system automatically performs syntax and structure validation on the uploaded file

h3. *AC2 – Validation Trigger on Submit (Creation)*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**When** I submit a new vocabulary via the UI\
**Then** the system performs syntax and structure validation as part of the submission flow

h3. *AC3 – Validation Trigger on Submit (Version Update)*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**When** I submit a new version of an existing vocabulary\
**Then** the system performs syntax and structure validation as part of the version submission flow

h3. *AC4 – Successful Validation*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**And** the uploaded or submitted vocabulary file contains no syntax or structure errors\
**When** validation is completed\
**Then** the system:\
- Marks the validation as successful\
- Displays a clear confirmation message indicating that syntax and structure validation passed\
- Allows the user to proceed with the flow

h3. *AC5 – Syntax Errors Detected*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**And** the uploaded or submitted vocabulary file contains syntax errors\
**When** validation is performed\
**Then** the system:\
- Displays a list of all detected syntax errors\
- Indicates the exact location of each error (e.g. line number, element, or path)\
- Prevents completion of the current flow

h3. *AC6 – Structure Errors Detected*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**And** the uploaded or submitted vocabulary file violates required structure rules\
**When** validation is performed\
**Then** the system:\
- Displays a list of all detected structure validation errors\
- Indicates the exact location of each error\
- Prevents completion of the current flow

h3. *AC7 – Multiple Errors Handling*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**And** the uploaded or submitted vocabulary file contains multiple syntax and/or structure errors\
**When** validation is performed\
**Then** the system:\
- Displays all detected errors in a single response\
- Does not stop validation after the first error\
- Prevents completion of the current flow

h3. *AC8 – Error Resolution Requirement*

**Given** I am authenticated as a Governance Authority with vocabulary management permissions\
**And** validation errors have been detected\
**When** I attempt to proceed without fixing the errors\
**Then** the system prevents continuation until all blocking syntax and structure errors are resolved
