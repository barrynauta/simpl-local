# SIMPL-18163: Sort and filter vocabulary list via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18163 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority\
**I want** to filter and sort the vocabulary list in the UI\
**so that** I can quickly find vocabularies based on status, name, or creation date

Acceptance Criteria\
**Given** I am authenticated as a Governance Authority and viewing the vocabulary list\
**When** I apply a filter (e.g., "Vocabulary Status = Deprecated" or "Name contains 'shacl'"){}\
**Then** the list updates to show only vocabularies that match the filter

**Given** I click on a sortable column header\
**When** the list is reloaded\
**Then** vocabularies are ordered according to that column in ascending or descending order
