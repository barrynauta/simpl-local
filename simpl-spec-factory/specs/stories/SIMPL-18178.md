# SIMPL-18178:  Warning on deprecated vocabularies in Vocabulary Management UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18178 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority,

**I want** to see a warning when deprecated vocabularies are present on the vocabulary management page

**So that** I am discouraged from using them in future resources

Acceptance Criteria

**Given** a vocabulary is deprecated

**When** I see a deprecated vocabulary

**Then** the system shows a clear warning message indicating deprecation
