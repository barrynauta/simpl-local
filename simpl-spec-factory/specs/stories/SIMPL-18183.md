# SIMPL-18183: Validate vocabulary semantics via API
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-07-16
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18183 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority\
**I want** semantic validation to be performed when I submit a vocabulary creation or new version request via the API\
**So that** I can integrate semantic checks into automated vocabulary pipelines without a separate validation endpoint



Acceptance Criteria

Positive Scenario – Semantic validation passes\
**Given** I am an authenticated Governance Authority user\
**And** I have a role allowing vocabulary management\
**And** the vocabulary has correct semantics\
**When** I submit a vocabulary creation or new version creation request via the API\
**And** the submitted vocabulary passes syntax validation\
**Then** semantic validation is performed\
**And** the vocabulary or vocabulary version is created

Negative Scenario – Semantic validation fails\
**Given** I am an authenticated Governance Authority user\
**And** I have a role allowing vocabulary management\
**And** the vocabulary contains semantic issues\
**When** I submit a vocabulary creation or new version creation request via the API\
**And** the submitted vocabulary passes syntax validation\
**Then** semantic validation is performed\
**And** a structured list of semantic errors or warnings is returned\
**And** the vocabulary or vocabulary version is not created

Note:

we can only validate against self managed vocabularies as it wouldn't be safe to fetch external vocabularies\
we issue warnings for external vocabularies that cannot be resolved\
when doing semantic validation don't fail on first issue - perform a full semantic validation and return all semantic errors
