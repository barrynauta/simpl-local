# SIMPL-18167: View version history of a vocabulary in the UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18167 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority
I want to view the version history of a selected vocabulary in the UI
so that I can understand how it has evolved over time

Acceptance Criteria
Given I am authenticated as a Governance Authority
And I have navigated to a vocabulary management page in the UI
When I open the history of a selected vocabulary
Then I am redirected to the vocabulary details page
And I see a chronological list of all versions of the vocabulary including:

Name (in the header)
Actions (Download)
Version (Version number)
Status (Active, Deprecated)
Date created
Description
Change log
