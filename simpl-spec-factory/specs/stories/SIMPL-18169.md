# SIMPL-18169: Create a new vocabulary via UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18169 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority user,\
**I want** to create a new vocabulary by entering metadata into the UI\
**so that** I can register a new controlled vocabulary for use in the data space

Acceptance Criteria

AC1 – Access to creation form and required fields\
**Given** I am authenticated and authorized as a Governance Authority user with vocabulary management permissions\
**When** I navigate to the Vocabulary Management UI\
**And** I click the “New Vocabulary +” button\
**Then** I am presented with a vocabulary creation form\
**And** the following required fields are available:

Name\
Description\
File upload\
**And** no field for version or change log is displayed

AC2 – Validation of input data\
**Given** I am authenticated and authorized as a Governance Authority user with vocabulary management permissions\
**And** I have completed the vocabulary creation form\
**When** I submit the form\
**Then** Simpl-Open validates that:

All required fields are provided\
Field formats are correct\
The vocabulary name is unique\
The uploaded file format is supported\
**And** if validation fails, I am informed with appropriate error messages in the UI
