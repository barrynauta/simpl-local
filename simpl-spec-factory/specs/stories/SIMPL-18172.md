# SIMPL-18172: Create a new version of a vocabulary via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18172 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority user,\
**I want** to create a new version of an existing vocabulary via the UI\
**So that** I can maintain and adapt vocabulary content according to evolving requirements

Acceptance Criteria

AC1 – Open update form with pre-filled data\
**Given** I am authenticated as a Governance Authority user with vocabulary management permissions\
**And** I am viewing an existing vocabulary management page\
**When** I click the three dots menu\
**And** I click the "Update" button\
**Then** I am presented with a form pre-filled with the existing vocabulary metadata and content

AC2 – Successfully create a new vocabulary version\
**Given** I am editing the vocabulary update form\
**When** I update the metadata and/or vocabulary content, including providing a change summary and uploading an updated file\
**And** I submit the form with all validations passing\
**Then** Simpl-Open creates a new vocabulary version linked to the previous versions\
**And** the new version is automatically marked as ACTIVE\
**And** all previous versions are automatically marked as DEPRECATED\
**And** a notification is displayed confirming that the new version was successfully created

AC3 – Handle unexpected system error during version creation (negative scenario)\
**Given** I have submitted the vocabulary update form\
**When** an unexpected error occurs during the creation of the new version\
**Then** Simpl-Open does not create a new version\
**And** I am presented with an error notification indicating that the operation failed\
**And** I am advised to retry or contact support
