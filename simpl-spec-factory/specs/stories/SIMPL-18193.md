# SIMPL-18193: Receive vocabulary validation report via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18193 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to receive a detailed validation report while submitting a vocabulary via the UI,\
**So that** I can review and correct any syntax or semantic errors before completing vocabulary creation or version update.

Acceptance Criteria\
Positive Scenario - Submitted vocabulary passes validation\
**Given** I am authenticated as a Governance Authority user\
**And** I upload or submit a vocabulary in the UI as part of vocabulary creation or version update\
**When** the submitted vocabulary passes validation\
**Then** the UI confirms successful validation\
**And** I can complete the flow without validation errors

Negative Scenario - Submitted vocabulary contains validation errors\
**Given** I am authenticated as a Governance Authority user\
**And** I upload or submit a vocabulary in the UI as part of vocabulary creation or version update\
**When** the submitted vocabulary contains validation errors\
**Then** the UI displays a detailed structured report highlighting the errors, including their nature and location\
**And** I cannot complete the flow until the blocking validation errors are resolved
