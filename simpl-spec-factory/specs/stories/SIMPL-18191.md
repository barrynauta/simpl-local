# SIMPL-18191: Automatic deprecation of previous vocabulary version UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18191 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

As a Governance Authority user,
I want to automatically deprecate previous vocabulary versions when I create a new version,
so that outdated vocabularies are no longer actively used but remain referenceable for backward compatibility.

Acceptance Criteria

AC1 – Automatic deprecation and activation
Given I am an authenticated Governance Authority user with permissions to manage vocabularies
And I create a new version of an existing vocabulary
When the new version is successfully created
Then the system sets the newly created version status to ACTIVE
And the system sets all previous versions of that vocabulary to DEPRECATED
