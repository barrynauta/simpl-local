# SIMPL-18161: View All vocabularies and their definitions via UI
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-09-25
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18161 (copied 2026-10-27)

## Description and acceptance criteria (as shown on the Jira issue page)

**As a** Governance Authority\
**I want** to view a list of all vocabularies and their current versions in the UI\
**so that** I can review them and check their current status and other related data

Acceptance Criteria\
Positive Scenario\
**Given** I am authenticated as a Governance Authority with a role authorizing vocabulary management\
**When** I navigate to the Vocabulary Management screen in the UI\
**Then** I see a list of all vocabularies, with each row showing: an expandable three-dot menu named actions, vocabulary name, description, current version, vocabulary status (`Active`, `Deprecated`), date created, last updated, and creator

Negative Scenario\
**Given** I am authenticated as a Governance Authority with a role authorizing vocabulary management\
**When** an error occurs while Simpl-Open processes my request to retrieve vocabularies in the UI\
**Then** I am informed that the vocabulary list could not be loaded\
**And** the UI displays the details about the error that occurred

Notes:

This story covers listing vocabularies in the Vocabulary Management UI.\
The minimum actions shown in the row-level three-dot menu are View vocabulary details and Download vocabulary. (these are not functional until their respective functionality is implemented SIMPL-18452)\
The detailed behaviour of each action is covered in separate user stories.
