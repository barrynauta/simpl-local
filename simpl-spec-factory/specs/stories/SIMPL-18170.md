# SIMPL-18170: Create a new vocabulary via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18170 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to create a new vocabulary by submitting its metadata via the API\
**So that** I can automate vocabulary creation

*Acceptance Criteria*\
**Given** I am authenticated as a Governance Authority with valid API credentials and authorised for vocabulary management\
**When** I submit metadata and content for a new vocabulary through the API\
**Then** the API validates the request\
**And** if validation succeeds, returns the newly created vocabulary identifier, metadata, and initial version details\
**And** the system automatically creates version 1 as the latest version with status ACTIVE\
**And** the vocabulary is created with default vocabulary status ACTIVE

**Given** the vocabulary is created via API\
**When** I retrieve the created vocabulary\
**Then** the response includes all provided metadata and version 1 with status ACTIVE\
**And** the vocabulary status is ACTIVE by default and can later be manually changed to DEPRECATED or back to ACTIVE

*Negative Scenario - Request contains invalid or incomplete vocabulary data*\
**Given** I am authenticated as a Governance Authority with valid API credentials and authorised for vocabulary management\
**When** I submit metadata and content for a new vocabulary through the API with invalid or incomplete data\
**Then** the API rejects the request with a validation error\
**And** no new vocabulary is created
