# SIMPL-18182: Validate vocabulary semantics via UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2025-09-10, updated: 2026-05-29
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18182 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** Simpl-Open to perform semantic validation automatically when I submit a vocabulary or a new vocabulary version via the UI\
**So that** I can ensure terms are unique, consistent, and logically coherent

Acceptance Criteria

**AC1 – Semantic validation triggered after syntax validation**\
**Given** a vocabulary or vocabulary version has passed syntax validation\
**When** the vocabulary version is submitted via the UI\
**Then** Simpl-Open performs semantic validation

**AC2 – Successful semantic validation**\
**Given** a vocabulary version is semantically valid\
**When** Simpl-Open completes semantic validation\
**Then** the validation result is successful

**AC3 – Semantic validation failure reporting**\
**Given** a vocabulary version contains semantic issues\
**When** Simpl-Open completes semantic validation\
**Then** Simpl-Open provides a structured report detailing semantic errors
