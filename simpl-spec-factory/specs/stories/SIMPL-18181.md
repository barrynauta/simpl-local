# SIMPL-18181: Validate vocabulary syntax via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18181 (collected 2026-10-27)

## Description and acceptance criteria

**As a** user with the _Vocabulary Management_ role\
**I want** the API to validate vocabulary syntax when I submit a vocabulary creation or new version creation request\
**So that** syntactically invalid vocabularies are rejected before semantic validation and version creation continue

Acceptance Criteria

Positive Scenario – Submitted vocabulary passes validation\
**Given** I am authenticated and authorised with the Vocabulary Management role\
**And** I submit a vocabulary creation or new version creation request via the API\
**And** the submitted vocabulary has valid syntax\
**When** the API processes the request\
**Then** the API validates the vocabulary syntax\
**And** the request passes the syntax validation step\
**And** the request is allowed to proceed to semantic validation\
**And** no syntax validation errors are returned\
**And** the API response or processing state indicates that syntax validation has passed

Negative Scenario – Submitted vocabulary contains syntax errors\
**Given** I am authenticated and authorised with the Vocabulary Management role\
**And** I submit a vocabulary creation or new version creation request via the API\
**And** the submitted vocabulary has invalid syntax\
**When** the API processes the request\
**Then** the API validates the vocabulary syntax\
**And** the request is rejected at the syntax validation step\
**And** semantic validation is not performed\
**And** the vocabulary is not created as an ACTIVE vocabulary\
**And** no new ACTIVE version is created\
**And** no previous versions are deprecated\
**And** the API returns a structured error response\
**And** the error response includes a list of syntax validation errors with precise locations and descriptions

Notes:

This story covers syntax validation only.\
Semantic validation is covered in a separate story.
