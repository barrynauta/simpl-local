# SIMPL-18168: Retrieve version history of a vocabulary via API
- Status: Ready for DG Acceptance
- Type: Story
- Created: 2025-09-10, updated: 2026-08-12
- Source: https://jira.simplprogramme.eu/browse/SIMPL-18168 (collected 2026-10-27)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to retrieve the full version history of a specific vocabulary via the API\
**So that** I can review how that vocabulary has evolved over time and use that history in external integrations or audits

Acceptance Criteria\
**Given** I am authenticated as a Governance Authority via API with valid credentials\
**And** I have identified an existing vocabulary\
**When** I request the full version history of a vocabulary\
**Then** the API returns a structured list of all versions with metadata needed for comparison

Negative Scenario - Requested vocabulary does not exist\
**Given** I am authenticated as a Governance Authority via API with valid credentials\
**And** I request the version history of a vocabulary that does not exist\
**When** the API processes my request\
**Then** the API returns an error indicating that the requested vocabulary could not be found

Note:\
Authentication and authorization are handled in this epic: [https://jira.simplprogramme.eu/browse/SIMPL-16635](https://jira.simplprogramme.eu/browse/SIMPL-16635)
