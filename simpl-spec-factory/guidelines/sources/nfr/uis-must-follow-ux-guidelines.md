# UIs must follow UX Guidelines

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/uis-must-follow-ux-guidelines](https://simpl-programme.ec.europa.eu/book-page/uis-must-follow-ux-guidelines)

## Description

Simpl-Open's development lifecycle shall ensure that all user interfaces (UIs) adhere to established UX guidelines to enhance user experience, consistency, and ease of use.

## SMART Breakdown

* Specific: Simpl-Open shall ensure that all user interfaces (UIs) adhere to established UX guidelines to enhance user experience, consistency, and ease of use.
* Measurable: The adherence to the UX guidelines will be measured by conducting usability testing, gathering user feedback, and performing evaluations to assess consistency and usability.
* Achievable: Achieved by working with a UX team to establish comprehensive guidelines and conducting user testing with tools like Figma or Sketch for prototype validation.
* Realistic: Following UX guidelines is an essential practice for ensuring the system’s usability and improving user satisfaction.
* Timely: Implemented during the design phase and continuously refined based on user feedback and usability testing throughout the lifecycle.
