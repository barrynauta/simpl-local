# 6.1 - A Consumer searches resources in the catalogues of a data space

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/61-consumer-searches-resources-catalogues-data-space](https://simpl-programme.ec.europa.eu/book-page/61-consumer-searches-resources-catalogues-data-space)

## Description

Simpl-Open shall allow a Consumer to search resources in the catalogues of the own data space and/or the catalogues of federated data spaces using quick keyword-based search and advanced search methods.

Issue ID: SIMPL-1329. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.1.1 - A Consumer searches resource descriptions in the catalogues of a data space using quick search**: Simpl-Open shall allow a Consumer to search resource descriptions in the catalogues of a data space via UI and API by: ; Selecting the catalogue for the search; ; Choosing the search method: quick or advanced; ; Providing one ore more search terms; ; Selecting the expected level of metadata quality of the search results: minimum metadata quality classification (e.g. only show resources with medium metadata quality classification or higher). The quick search method maps the provided search terms to any of the properties of the resource description. (SIMPL-469) [Details](https://simpl-programme.ec.europa.eu/book-page/611-consumer-searches-resource-descriptions-catalogues-data-space-using-quick-search)
- **6.1.2 - A Consumer searches in the catalogues of a federated data space**: Simpl-Open shall allow a Consumer to search resource descriptions in the catalogues of a federated data space via UI and API by: ; Selecting one or several federated catalogues for the search; ; Searching in all federated catalogues without explicitely selecting them; ; Choosing the search method: quick or advanced; ; Providing one ore more search terms (SIMPL-25100) [Details](https://simpl-programme.ec.europa.eu/book-page/612-consumer-searches-catalogues-federated-data-space)
