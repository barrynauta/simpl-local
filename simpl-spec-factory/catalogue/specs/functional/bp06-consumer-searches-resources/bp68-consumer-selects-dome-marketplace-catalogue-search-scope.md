# 6.8 - The Consumer selects the DOME Marketplace catalogue as a search scope

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/68-consumer-selects-dome-marketplace-catalogue-search-scope](https://simpl-programme.ec.europa.eu/book-page/68-consumer-selects-dome-marketplace-catalogue-search-scope)

## Description

Simpl-Open shall enable the Consumer to include the DOME Marketplace catalogue as an additional search scope when DOME discovery is enabled for the data space. DOME is queried only when the Consumer selects it.

Issue ID: SIMPL-6760. Status at time of capture (5 October 2026): Proposed.

## Detailed Requirements

None published at the time of capture.
