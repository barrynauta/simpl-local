# 6.6 - A Governance Authority provides resources

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/66-governance-authority-provides-resources](https://simpl-programme.ec.europa.eu/book-page/66-governance-authority-provides-resources)

## Description

Simpl-Open shall support the Governance Authority to provide a Consumer the resource descriptions matching its search request.

Issue ID: SIMPL-28856. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.6.1 - A Governance Authority provides resources descriptions matching a search request to a Consumer**: Simpl-Open shall support the Governance Authority to provide a Consumer the collected resource descriptions from own and federated catalogues across data spaces, matching the Consumer's search request. (SIMPL-28870) [Details](https://simpl-programme.ec.europa.eu/book-page/661-governance-authority-provides-resources-descriptions-matching-search-request-consumer)
