# 6.4 - A Trustor Governance Authority provides the results for a search request to a trusted data space

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/64-trustor-governance-authority-provides-results-search-request-trusted-data-space](https://simpl-programme.ec.europa.eu/book-page/64-trustor-governance-authority-provides-results-search-request-trusted-data-space)

## Description

Simpl-Open shall support a Trustor Governance Authority to provide the results for a search request to the Trusted Governance Authority that forwarded the request.

Issue ID: SIMPL-28855. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.4.1 - A Trustor Governance Authority provides resource descriptions matching a forwarded search request to a Trusted Governance Authority**: Simpl-Open shall support a Trustor Governance Authority to automatically provide resource descriptions to a Trusted Governance Authority in reply to a forwarded search request. The search results are returned to the requesting Trusted Governance Authority (not to the Consumer).
