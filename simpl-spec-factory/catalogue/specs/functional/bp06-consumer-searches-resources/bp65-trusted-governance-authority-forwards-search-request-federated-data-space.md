# 6.5 - A Trusted Governance Authority forwards a search request to a federated data space

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/65-trusted-governance-authority-forwards-search-request-federated-data-space](https://simpl-programme.ec.europa.eu/book-page/65-trusted-governance-authority-forwards-search-request-federated-data-space)

## Description

Simpl-Open shall support a Trusted Governance Authority to forward search requests from consumers involving one or more federated catalogues.

Issue ID: SIMPL-28853. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.5.1 - A Trusted Governance Authority forwards a search request to a Trustor Governance Authority**: Simpl-Open shall support a Trusted Governance Authority to handle search requests from consumers involving one or more federated catalogues by ; Identifying for each of the selected federated catalogues, the relevant Trustor Governance Authority ; Forwarding the search request with the relevant catalogues to the identified Trustor Governance Authority on behalf of its Consumer ; providing the identity attributes of the Consumer together with the request. (SIMPL-27800) [Details](https://simpl-programme.ec.europa.eu/book-page/651-trusted-governance-authority-forwards-search-request-trustor-governance-authority)
