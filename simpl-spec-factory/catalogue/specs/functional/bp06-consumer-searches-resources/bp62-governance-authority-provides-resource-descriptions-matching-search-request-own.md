# 6.2 - A Governance Authority provides resource descriptions matching a search request from own catalogues

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/62-governance-authority-provides-resource-descriptions-matching-search-request-own](https://simpl-programme.ec.europa.eu/book-page/62-governance-authority-provides-resource-descriptions-matching-search-request-own)

## Description

Simpl-Open shall support a Governance Authority to provide resource descriptions matching a search request from a Consumer. These resource descriptions are searched in catalogues of its own data space.The resource descriptions matching the search criteria must comply to the discovery access policies enforced by Simpl-Open in the own data space.

Issue ID: SIMPL-23878. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.2.1 - The Governance Authority provides resource descriptions matching a search request**: Simpl-Open shall support the Governance Authority to automatically provide resource descriptions that: ; Belong to the selected catalogue of the search in the data space; ; Match the chosen search method (quick or advanced); ; Match the submitted search terms; ; Matching the selected metadata quality level; and ; Comply to the discovery access policies enforced by Simpl-Open.
