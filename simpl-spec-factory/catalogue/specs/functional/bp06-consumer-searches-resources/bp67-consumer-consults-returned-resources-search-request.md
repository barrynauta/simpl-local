# 6.7 - A Consumer consults the returned resources of a search request

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/67-consumer-consults-returned-resources-search-request](https://simpl-programme.ec.europa.eu/book-page/67-consumer-consults-returned-resources-search-request)

## Description

Simpl-Open shall allow a Consumer to consult the returned resource descriptions of a search request.

Issue ID: SIMPL-4492. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.7.1 - A Consumer consults the overview of resource descriptions returned from own catalogues by a search request**: Simpl-Open shall allow a Consumer to consult via UI and API, a list of resource descriptions from its own data space's catalogues that was returned by a search request. This list includes for each resource description: ; Main properties of the matching resource descriptions; ; Overall metadata quality score and quality classification. This list can be sorted based on the main properties and quality properties. (SIMPL-4497) [Details](https://simpl-programme.ec.europa.eu/book-page/671-consumer-consults-overview-resource-descriptions-returned-own-catalogues-search)
- **6.7.2 - A Consumer consults the overview of resource descriptions returned by a search request from a federated catalogue**: Simpl-Open shall allow a Consumer to consult via UI and API, a list of resource descriptions from a federated catalogue of a data space that was returned by a search request. This list includes for each resource description: ; Main properties of the matching resource descriptions. This list can be sorted based on the main properties. For a federated search, sorting may not apply to quality properties, as the definition of data quality can deviate between different data spaces. (SIMPL-27804) [Details](https://simpl-programme.ec.europa.eu/book-page/672-consumer-consults-overview-resource-descriptions-returned-search-request-federated)
- **6.7.3 - A Consumer consults the details of a resource description returned from an own catalogue by a search request**: Simpl-Open shall allow a Consumer to consult via UI and API, the details of a resource description from its own data space's catalogue that was returned by a search request. This includes following information about the selected resource description: ; All published properties of the resource description; ; The overall metadata quality score and quality classification; ; The metadata quality score and quality classification for each dimension. (SIMPL-23885) [Details](https://simpl-programme.ec.europa.eu/book-page/673-consumer-consults-details-resource-description-returned-own-catalogue-search-request)
- **6.7.4 - A Consumer consults the details of a resource description returned by a search request from a federated catalogue**: Simpl-Open shall allow a Consumer to consult the details of a resource description returned by a search request via UI and AP from a federated catalogue, which includes following information about the selected resource description: ; All published properties of the resource description. (SIMPL-27805) [Details](https://simpl-programme.ec.europa.eu/book-page/674-consumer-consults-details-resource-description-returned-search-request-federated)
- **6.7.5 - A Trusted Governance Authority forwards a request for the details of a resource description to a Trustor Governance Authority**: Simpl-Open shall support a Trusted Governance Authority to handle requests for the details of a resource description from Consumers involving a federated catalogue by ; Identifying the federated catalogue and the relevant Trustor Governance Authority of the resource description ; Forwarding the request to the identified Trustor Governance Authority on behalf of its Consumer ; providing the identity attributes of the Consumer together with the request. (SIMPL-27806) [Details](https://simpl-programme.ec.europa.eu/book-page/675-trusted-governance-authority-forwards-request-details-resource-description-trustor)
- **6.7.6 - A Governance Authority maps the identity attributes for a resource description request received from a Trusted Governance Authority**: Simpl-Open shall support a Governance Authority receiving a request for details of a resource description from Trusted Governance Authority. Furthermore, Simpl-Open shall support the Governance Authority to map the identity attributes based on the identity attribute mapping defined during the federation configuration, that it receives along with the request. This will ensure correct authorisation and policy enforcement in the trustor data space. (SIMPL-27807) [Details](https://simpl-programme.ec.europa.eu/book-page/676-governance-authority-maps-identity-attributes-resource-description-request-received)
- **6.7.7 - A Governance Authority provides the details of a resource description to a Trusted Governance Authority**: Simpl-Open shall support a Governance Authority to automatically provide the details of a resource description from an own catalogue to a Trusted Governance Authority in reply to a forwarded request. The details of the resource description is returned to the requesting Trusted Governance Authority (not to the Consumer). (SIMPL-28871) [Details](https://simpl-programme.ec.europa.eu/book-page/677-governance-authority-provides-details-resource-description-trusted-governance)
- **6.7.8 - A Governance Authority provides the details of a resource description from a federated catalogue**: Simpl-Open shall support a Governance Authority to receive the details of a requested resource description from a Trustor Governance Authority and provide them to the Consumer that requested the resource description. (SIMPL-28872) [Details](https://simpl-programme.ec.europa.eu/book-page/678-governance-authority-provides-details-resource-description-federated-catalogue)
