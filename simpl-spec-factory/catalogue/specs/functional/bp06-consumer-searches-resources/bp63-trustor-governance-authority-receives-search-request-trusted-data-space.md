# 6.3 - A Trustor Governance Authority receives a search request from a trusted data space

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/63-trustor-governance-authority-receives-search-request-trusted-data-space](https://simpl-programme.ec.europa.eu/book-page/63-trustor-governance-authority-receives-search-request-trusted-data-space)

## Description

Simpl-Open shall support a Governance Authority to handle a search request received from a Trusted Governance Authority.

Issue ID: SIMPL-28854. Status at time of capture (15 September 2026): Proposed.

## Detailed Requirements

- **6.3.1 - A Governance Authority maps the identity attributes for a search received from a Trusted Governance Authority**: Simpl-Open shall support a Governance Authority receiving a search of a Trusted Governance Authority, along with the relevant attributes of the Consumer, to map these identity attributes based on the mapping defined during federation. (SIMPL-28867) [Details](https://simpl-programme.ec.europa.eu/book-page/631-governance-authority-maps-identity-attributes-search-received-trusted-governance)
- **6.3.2 - A Governance Authority provides resource descriptions matching a search request received from a Trusted Governance Authority**: Simpl-Open shall support a Governance Authority, receiving a search request from a Trusted Governance Authority, to automatically provide resource descriptions that: ; Belong to the catalogue of its data space provided in the search; ; Match the chosen search method (quick or advanced); ; Match the submitted search terms; and ; Comply to the discovery access policies taking into account the mapped identity attributes. (SIMPL-28868) [Details](https://simpl-programme.ec.europa.eu/book-page/632-governance-authority-provides-resource-descriptions-matching-search-request-received)
