# 5B.1 - A Provider consults its own Resource descriptions

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b1-provider-consults-its-own-resource-descriptions](https://simpl-programme.ec.europa.eu/book-page/tbp-5b1-provider-consults-its-own-resource-descriptions)

## Description

Simpl-Open shall allow a Provider to consult its own resource descriptions.

## Detailed Requirements

- **5B.1.1 – A Provider consults an overview of its Resource descriptions** — Simpl-Open enables providers to access a comprehensive view of their resource descriptions through both user interface and API. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b11-provider-consults-overview-its-resource-descriptions)
- **5B.1.2 – A Provider consults the details of one of its own resource descriptions** — Simpl-Open allows providers to examine specific details of individual resource descriptions via UI and API interfaces. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b12-provider-consults-details-one-its-own-resource-descriptions)
- **5B.1.3 – A Provider consults the version history of one of its own resource descriptions** — Simpl-Open provides providers access to the version history of their resource descriptions through UI and API. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b13-provider-consults-version-history-one-its-own-resource-descriptions)
