# 5B.2 - A Provider creates a new Resource description

## Canonical source
[https://simpl-programme.ec.europa.eu/book-page/tbp-5b2-provider-creates-new-resource-description](https://simpl-programme.ec.europa.eu/book-page/tbp-5b2-provider-creates-new-resource-description)

## Description

Simpl-Open shall enable providers to create new resource descriptions based on the latest versions of the resource description schema for the resource types.

## Detailed Requirements

- **5B.2.1 – A provider retrieves a Resource type** — Simpl-Open shall allow a Provider via UI and API to retrieve resource types. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b21-provider-retrieves-resource-type)
- **5B.2.2 – A Provider adds common metadata to a new Resource description** — Simpl-Open shall allow and support a Provider via UI and API to add common metadata. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b22-provider-adds-common-metadata-new-resource-description)
- **5B.2.3 – A Provider adds resource type specific metadata to a new Resource description** — Simpl-Open shall allow a Provider via UI and API to add type-specific metadata. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b23-provider-adds-resource-type-specific-metadata-new-resource-description)
- **5B.2.4 – A Provider assigns access policies to a new Resource description** — Simpl-Open shall allow a Provider via UI and API to assign access policies. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b24-provider-assigns-access-policies-new-resource-description)
- **5B.2.5 – A Provider assigns usage policies to a new Resource description** — Simpl-Open shall allow a Provider via UI and API to assign usage policies. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b25-provider-assigns-usage-policies-new-resource-description)
- **5B.2.6 – A Provider adds a set of contract clauses to a new resource description** — Simpl-Open shall allow a Provider via UI and API to add contract clauses. [Details](https://simpl-programme.ec.europa.eu/book-page/tbp-5b26-provider-adds-set-contract-clauses-new-resource-description)
