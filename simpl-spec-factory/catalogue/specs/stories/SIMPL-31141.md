# SIMPL-31141: [UI] A Consumer consults the overview of resource descriptions returned by a search request via UI
- Status: PBI for SC review
- Type: Story
- Created: 2026-08-04, updated: 2026-10-26
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31141 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Consumer\
**I want** to consult an overview of the search results from my data space catalogues via UI\
**So that** I can decide on further actions.

Acceptance criteria

**Given** I am a Consumer that has submitted a quick or advanced search request including catalogues of my own data space

**When** my Governance Authority returns the results

**Then** the results are a list of resource descriptions returned via UI

**And** these resource descriptions match the terms in my search request

**And** these resource descriptions are from one of the selected catalogues in search request from my data space

**And** for each resource description in the list I receive the main properties

Technical Design:\
- enhance existing search UI to display results in tabbed tables for each catalogue\
- test cases
