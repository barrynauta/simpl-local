# SIMPL-31114: A Governance Authority maps identity attributes from a federated search request
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-08-03, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31114 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to map the identity attributes received along with a search request from Trusted Governance Authorities\
**So that** I can properly evaluate the discovery access policies.

Acceptance criteria

**When** I, the Governance Authority receive a valid federated search request via API\
**And** the request includes the Customer's public identity attributes

**Then** Simpl-Open shall map the received identity attributes according to the federation-defined attribute mappings\
**And** make the mapped attributes available for the evaluation of discovery access policies.

Note:\
This US is covered with the implementation of [Simpl-34213](https://jira.simplprogramme.eu/browse/SIMPL-34213) for quick search and [Simpl-34211](https://jira.simplprogramme.eu/browse/SIMPL-34211) for advanced search where the identity attributes of the consumer are extracted in conjunction with [Simpl-31138](https://jira.simplprogramme.eu/browse/SIMPL-31138) for quick search and [Simpl-31139](https://jira.simplprogramme.eu/browse/SIMPL-31139) for advanced search where the mapping of the identity attributes to the trustor GA is done and only for linkage to the epic.
