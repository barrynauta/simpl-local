# SIMPL-31767: [BE] A Consumer consults the overview of resource descriptions returned by a search request via API
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2026-08-17, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31767 (collected 2026-10-28)

## Description and acceptance criteria

As a Consumer\
I* *want to consult an overview of the search results from my data space catalogues via API\
**So that** I can decide on further actions.

Acceptance criteria

**Given** I am a Consumer that has submitted a quick or advanced search request including catalogues of my own data space

**When** my Governance Authority returns the results

**Then** the results are a list of resource descriptions returned via API

**And** these resource descriptions match the terms in my search request

**And** these resource descriptions are from one of the selected catalogues in search request from my data space

**And** for each resource description in the list I receive the main properties


Note

This US is covered with the implementation of https://jira.simplprogramme.eu/browse/SIMPL-33462 for quick search results and https://jira.simplprogramme.eu/browse/SIMPL-33465 for advanced search results and only for linkage to the epic.
