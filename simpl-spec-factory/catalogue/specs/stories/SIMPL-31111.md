# SIMPL-31111: The Governance Authority filters resource descriptions matching a quick search request from own catalogues
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-08-03, updated: 2026-10-20
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31111 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to provide resource descriptions for a [quick search request](https://jira.simplprogramme.eu/browse/SIMPL-30598), belonging to the selected catalogues of the own data space, matching the submitted search terms and complies with the discovery access policies\
**So that** the Consumer can consult them.

Acceptance criteria

**When** I, the Governance Authority, receive a quick search request from a Consumer of my own data space\
**And** the Consumer is authorised with the identity attributes for searching\
**Then** I select the resource descriptions belong to one of my catalogues specified in the search query

**And** I filter on those for which at least one of the search terms is found in at least one of its properties

**And** I filter on those for which the Consumer's attributes comply with its discovery access policies

**And** I return this filtered list of resource descriptions

Note:\
This US is covered with the already implemented quick search request on query-mapper also providing the meta data quality data and only for linkage to the epic.
