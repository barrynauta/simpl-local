# SIMPL-31103: [UI] A Consumer selects federated catalogues for advanced search via UI
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2026-08-03, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31103 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Consumer\
**I want** to be able to select one or more catalogues from the catalogues of all trustor authorities in which the advanced search is performed\
**So that** I can find resource descriptions of the selected resource types.

Technical Details:\
The API used to retrieve the list of trusted dataspaces is exposed by the `xfsc-adv-search` component through the API implemented under ticket SIMPL-33471.\
The Catalogue UI invokes this API during the initialization of the Advanced Search workflow in order to populate the catalogue selection component.\
If the catalogue retrieval API is unavailable or returns an error, the catalogue selection component shall not be populated and an appropriate error message shall be displayed to the user.

Acceptance criteria

AC1

**Given** I am authenticated as a Consumer\
**And** I have a role authorising searching\
**When** I start advanced search\
**Then** Simpl-Open allows me to select one or more catalogues from the catalogues of all trustor authorities via UI

AC2

**Given** I am authenticated as a Consumer\
**And** I have a role authorising searching\
**When** I start Advanced Search\
**And** the catalogue retrieval API cannot successfully return the list of federated catalogues\
**Then** the catalogue selection component is not populated\
**And** an appropriate error message is displayed to the user.
