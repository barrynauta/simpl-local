# SIMPL-30848: Trusted GA configure Search endpoint of a trustor data space
- Status: PBI Defined
- Type: Story
- Created: 2026-07-28, updated: 2026-10-20
- Source: https://jira.simplprogramme.eu/browse/SIMPL-30848 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Trusted Governance Authority\
**I want** to configure the federated search endpoint of a Trustor data space\
**So that** federated search requests from my consumers can be properly forwarded.

Acceptance Criteria

**Given** I am authenticated as a Trusted Governance Authority, with a role authorising __ federated search configuration

**When** I provide the endpoint details of a Trustor Governance Authority

**Then** Simpl-Open shall store the endpoint configuration\
**And** enable the Consumer to choose the catalogue of the Trustor Governance Authority.

*Note*: This US is covered with the implementation of [https://code.europa.eu/simpl/simpl-open/security/access-control-and-trust/authentication-provider-federation/authentication-provider/authentication-provider-be/-/blob/main/openapi/authenticationprovider-tier1-v2.yaml] and only for linkage to the epic.

For each data space there is only one SIMPL open catalogue with a given simpl specific prefix, hence the catalogue url is <base-url> + "catalogue-suffix"
