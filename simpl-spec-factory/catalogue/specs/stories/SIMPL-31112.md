# SIMPL-31112: The Governance Authority filters resource descriptions matching an advanced search request from own catalogues
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-08-03, updated: 2026-10-20
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31112 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority\
**I want** to provide resource descriptions for an advanced search request ([Simpl-30600](https://jira.simplprogramme.eu/browse/SIMPL-30600)), belonging to the selected catalogue of the own data space, matching the submitted search terms and complying with the discovery access policies\
**So that** the Consumer can consult them.

Acceptance criteria

**When** I, the Governance Authority, receive a advanced search request from a Consumer of my own data space\
**And** the Consumer is authorised with the identity attributes for searching\
**Then** I select the resource descriptions belonging to my selected catalogue specified in the search query

**And** I filter on those for which each search term is found in the property to which it was submitted

**And** I filter on those for which the Consumer's attributes comply with its discovery access policies

**And** I return this filtered list of resource descriptions

*Note:*\
This US is covered with the already implemented advanced search request on query-mapper also providing the meta data quality data and only for linkage to the epic.
