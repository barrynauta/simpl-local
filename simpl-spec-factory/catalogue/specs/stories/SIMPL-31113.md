# SIMPL-31113: A Trusted Governance Authority forwards federated search requests to Trustor Governance Authorities via API
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-08-03, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31113 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Trusted Governance Authority,\
**I want** to route search requests to the relevant Trustor Governance Authorities and provide the Consumer's identity attributes via API,\
**So that** federated catalogue searches can be executed on behalf of Consumers across dataspaces.

Acceptance criteria

AC 1 positive path:\
**When** I, the Trusted Governance authority receive a valid search request\
**And** one or more federated catalogue is selected\
**Then** Simpl-Open shall forward the search request to each relevant Trustor Governance Authority via API\
**And** include the federated catalogues associated with that Trustor Governance Authority\
**And** include the Consumer's public identity attributes

AC 2 negative path: trustor GA no longer trust trusted governance authority\
**When** I, the Trusted Governance authority receive a valid search request\
**And** one or more federated catalogue is selected\
**And** there is one federated catalogue selected of a trustor governance authority that no longer consider trusted GA as trusted\
**Then** Simpl-Open reject the call to this trustor GA with an error code 502 failed mTLS handshake

AC 3 negative path: catalogue selected which does not belong to a federated GA\
**When** I, the Trusted Governance authority receive a valid search request\
**And** one or more federated catalogue is selected\
**And** there is one federated catalogue selected which does not belong to a federation\
**Then** Simpl-Open reject the call to this trustor GA with an error code 502 failed mTLS handshake
