# SIMPL-31768: A Consumer consults the overview of resource descriptions returned from federated catalogues by a search request via API
- Status: For PSO Review
- Type: Story
- Created: 2026-08-17, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31768 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Consumer\
**I want** to consult an overview of the search results from the federated data space catalogues via API\
**So that** I can decide on further actions.

Acceptance criteria

**Given** I am a Consumer that has submitted a quick or advanced search request to catalogues of federated data spaces

**When** my Governance Authority returns the results

**Then** the results are a list of resource descriptions returned via API

**And** these resource descriptions are retrieved only from the catalogues of federated data spaces specified in my search request

**And** for each resource description in the list I receive the main properties

Note\
This US is covered with the implementation of [https://jira.simplprogramme.eu/browse/SIMPL-33462](https://jira.simplprogramme.eu/browse/SIMPL-33462) for quick search results and [https://jira.simplprogramme.eu/browse/SIMPL-33465](https://jira.simplprogramme.eu/browse/SIMPL-33465) for advanced search results and only for linkage to the epic.
