# SIMPL-35874: [UI] Advanced Search: Use SEARCH Schema for Federated Catalogue Queries
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-10-26, updated: 2026-10-28
- Source: https://jira.simplprogramme.eu/browse/SIMPL-35874 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Consumer\
**I want** to see the appropriate search fields based on the catalogues selected for my search\
**So that** I can perform searches using a schema that is compatible with the selected search scope (local or federated).

Technical Details:\
The Advanced Search UI shall adapt the search form according to the selected catalogues.

If the Consumer selects only the local catalogue, the UI shall display the list of schemas available in the current data space. Once a schema is selected, the corresponding search fields shall be presented to the user.

If at least one federated catalogue is selected, the UI shall automatically use the schema of type *SEARCH* (see related ticket) as the reference schema and directly display its search fields, without requiring the user to select a schema.

To support this behavior, *catalogue-ui* shall invoke the schema retrieval API with the parameter `schemaType=SEARCH` whenever a federated search is requested.

Acceptance criteria

AC1\
**Given** I am performing an advanced search and only the local catalogue is selected\
**When** the search form is displayed\
**Then** I can see the list of schemas available in the current data space\
**And** I can select one of them to view its related search fields

### AC2\
**Given** I am performing an advanced search and at least one federated catalogue is selected\
**When** the search form is displayed\
**Then** the UI automatically retrieves the schema of type *SEARCH*\
**And** the related search fields are displayed without requiring a schema selection

### AC3\
**Given** I am performing a federated search\
**When** catalogue-ui requests the schema definition\
**Then** the schema retrieval API is invoked with the parameter `schemaType=SEARCH`\
**And** the returned schema is used to build the search form.
