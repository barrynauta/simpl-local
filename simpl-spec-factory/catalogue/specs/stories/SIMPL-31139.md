# SIMPL-31139: [API Implementation]A Governance Authority provides resource descriptions matching an advanced search request from a Trusted Governance Authority

- Type: Story
- Created: 2026-08-04, updated: 2026-10-23
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31139 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to provide resource descriptions for an advanced search request, belonging to the selected federated catalogue of my data space, matching the submitted search terms and complies with the discovery access policies\
**So that** the resource description can be provided to the Trusted Governance Authority.

Acceptance criteria

## AC1 - Trusted GA requests advanced search result from trustor

**Given** I am a Trustor GA

**When** I receive an advanced search request from a Trusted Governance Authority\
**And** the Consumer's identity attributes are mapped according to the federation-defined attribute mappings

**Then** a list of resource descriptions is returned

**And** the returned list only includes resource descriptions belonging to the catalogue specified in the search query

**And** the returned list only includes resource descriptions whose properties match the search terms for that property

**And** the returned list only includes resource descriptions whose discovery access policies are satisfied considering the mapped identity attributes

## AC2 - Non trusted GA request advanced search result from trustor

**Given** I am a Trustor GA\
**When** I receive an advanced search request from someone who is not a Trusted GA

**Then** I reject the request with error code 403

## AC3 - Return empty result if no matching search results can be found

**Given** I am a Trustor GA\
**When** the valid and authorized search request does not find any matching search results\
**Then** the Trustd GA receives an empty list.
