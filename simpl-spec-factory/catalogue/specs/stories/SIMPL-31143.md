# SIMPL-31143: A Consumer consults the full contents of a resource description returned by a search request via UI
- Status: PBI for SC review
- Type: Story
- Created: 2026-08-04, updated: 2026-10-23
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31143 (collected 2026-10-28)

## Description and acceptance criteria

||As a|Consumer|\
||I want|to consult the details of a resource description found by a search from an own catalogue of the data space|\
||So that|I can decide on further actions and can start the contract negotiation.|

# Acceptance criteria

||Scenario|Consultation of the details of a resource description found by a search from an own catalogue of the data space|\
**Given** I am a Consumer that has requested the details of a resource description from an own catalogue of the data space\
**When** my Governance Authority returns the details of requested resource description\
**Then** all published properties of the resource description are returned via UI\
**And** the overall metadata quality score, quality classification is returned\
**And** the metadata quality score and quality classification for each dimension is returned

*Technical Design:*\
* enhance existing search UI to display results in tabbed tables for each catalogue\
* call QueryHandler on GA\
* test cases
