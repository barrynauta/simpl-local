# SIMPL-33885: [API Implementation] API to get detail of federated resource description (xfsc-adv-search)
- Status: DevTeam PBI is ready for Implementation check
- Type: Story
- Created: 2026-09-25, updated: 2026-10-19
- Source: https://jira.simplprogramme.eu/browse/SIMPL-33885 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Consumer,\
**I want** to retrieve the details of a Resource Description from a federated catalogue by providing the corresponding dataspace/catalogue identifier,\
**So that** I can access the correct Resource Description details and its associated schema from the federated catalogue where the resource is hosted.

Technical Description

Update the existing `xfsc-adv-search` API to accept the `dataspace/catalogue identifier` as an additional input parameter when requesting the details of a Resource Description.

The API shall use the provided dataspace/catalogue identifier to invoke the corresponding API exposed by the `query-mapper-adapter`, which is responsible for retrieving the Resource Description details and its associated schema from the appropriate federated catalogue. This ensures that, after selecting a Resource Description from federated search results, the Consumer is routed to the correct catalogue and receives the related metadata and schema information.

Acceptance Criteria\
AC1 - Successful retrieval of Resource Description details

**Given** a valid Resource Description identifier and a valid dataspace/catalogue identifier associated with a federated catalogue,\
**When** the Consumer requests the Resource Description details,\
**Then** the system shall route the request to the specified federated catalogue and return the Resource Description details together with the related schema.

Expected Response:\
- HTTP `200 OK`\
- Resource Description details returned successfully\
- Associated schema returned successfully

AC2 – Missing or Invalid Dataspace/Catalogue Identifier

**Given** a Consumer requests the details of a Resource Description\
**When** the request contains a missing or malformed dataspace/catalogue identifier\
**Then** the request is rejected\
**And** the API returns `HTTP 400 Bad Request`\
**And** an error response is returned indicating that the dataspace/catalogue identifier is invalid.

AC3 – Resource Description Not Found

**Given** a valid Resource Description identifier and a valid dataspace/catalogue identifier\
**When** the downstream query-mapper-adapter service identifies that the requested Resource Description does not exist in the target catalogue\
**Then** the API propagates the corresponding error response returned by the query-mapper-adapter service\
**And** the API returns `HTTP 404 Not Found`

AC4 – Unexpected Processing Error

**Given** a Consumer requests the details of a Resource Description\
**When** an unexpected error occurs while processing the request\
**Then** the API returns `HTTP 500 Internal Server Error`\
**And** an appropriate error response is returned.
