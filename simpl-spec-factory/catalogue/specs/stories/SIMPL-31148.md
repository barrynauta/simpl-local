# SIMPL-31148: [UI] A Consumer consults the full contents of a resource description returned from a federated catalogue by a search request via UI
- Status: PBI Defined
- Type: Story
- Created: 2026-08-04, updated: 2026-10-19
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31148 (collected 2026-10-28)

## Description and acceptance criteria

||As a|Consumer|\
||I want|to consult the details (all properties) of a resource description found by a search from a federated catalogue of a data space via UI|\
||So that|I can decide on further actions and can start the contract negotiation.|\
Acceptance criteria\
AC1 – Consult federated Resource Description details

**Given** I am a Consumer that has requested the details of a Resource Description from a federated catalogue of a dataspace\
**When** the Governance Authority successfully returns the Resource Description details and the associated schema\
**Then** the UI is dynamically generated using the schema returned by the backend\
**And** all published properties of the requested Resource Description are displayed in the UI

AC2 – Resource Description details retrieval failure

**Given** I am a Consumer that has requested the details of a Resource Description from a federated catalogue of a dataspace\
**When** the Resource Description details cannot be retrieved due to a backend or downstream service failure\
**Then** the UI displays an appropriate error message\
**And** no Resource Description details are displayed to the user.


AC3 – Invalid Resource Description request

**Given** I am a Consumer that has requested the details of a Resource Description from a federated catalogue of a dataspace\
**When** the request is rejected due to invalid or missing mandatory parameters\
**Then** the UI displays an appropriate validation error message\
**And** the Resource Description details page is not rendered.\
Technical Design:\
- The schema to show the details for a RD from a federated search cannot be revieced by the schema manager (because it is the schema of the trustor dataspace)\
- The backend call to the xsfc-adv-search-be to get the details will also get the schema to be used to display, this schema should be use to generate the frontend see SIMPL-31770\
- The visual display is the same for the federated case and same dataspace case

Display (no visual change only change where to get the schema to display)
