# SIMPL-31149: A Governance Authority forwards a request for the details of a resource description to a Trustor Governance Authority via API
- Status: FOR SC TO RESPOND
- Type: Story
- Created: 2026-08-04, updated: 2026-10-27
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31149 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to route the request for the details of a resource description to the relevant Trustor Governance Authority and provide the Consumer's identity attributes via API,\
**So that** requests for the details of the resource description can be executed on behalf of Consumers in the federated data space.

Note

This ticket is for tracking purpose to link to the ticket to the epic. The feature will be implemented in [https://jira.simplprogramme.eu/browse/SIMPL-31153], as it is one API for both User Stories. And the testing of the forwarding of the request is not possible to test without the recieving part.
