# SIMPL-31138: [API-Implementation] A Governance Authority provides resource descriptions matching a quick search request from a Trusted Governance Authority
- Status: FOR SC TO RESPOND

- Source: https://jira.simplprogramme.eu/browse/SIMPL-31138 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to provide resource descriptions for a quick search request, belonging to the selected federated catalogues of my data space, matching the submitted search terms and complies with the discovery access policies\
**So that** the resource description can be provided to the Trusted Governance Authority.

Acceptance criteria

## AC1 - Trusted GA requests quick search result from trustor

**Given** I am a Trustor Governance Authority

**When** I receive a quick search request from a Trusted Governance Authority\
**And** the Consumer's identity attributes are mapped according to the federation-defined attribute mappings

**Then** a list of resource descriptions is returned

**And** the returned list only includes resource descriptions belonging to the catalogues specified in the search query

**And** the returned list only includes resource descriptions for which at least one of the properties match the search terms

**And** the returned list only includes resource descriptions whose discovery access policies are satisfied considering the mapped identity attributes

## AC2 - Non trusted GA request quick search result from trustor

**Given** I am a Trustor GA\
**When** I receive a quick search request from someone who is not a Trusted GA

**Then** I reject the request with error code 403

## AC3 - Return empty result if no matching search results can be found

**Given** I am a Trustor GA\
**When** the valid and authorized search request does not find any matching search results\
**Then** the Trusted GA receives an empty list.
