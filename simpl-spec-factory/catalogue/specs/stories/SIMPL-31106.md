# SIMPL-31106: A Trustor Governance Authority provides resource descriptions matching a forwarded federated search request to a Trusted Governance Authority via API
- Status: PBI For DG Review
- Type: Story
- Created: 2026-08-03, updated: 2026-10-23
- Source: https://jira.simplprogramme.eu/browse/SIMPL-31106 (collected 2026-10-28)

## Description and acceptance criteria

**As a** Governance Authority,\
**I want** to automatically provide resource descriptions returned for a forwarded federated search request to the Trusted Governance Authority via API\
**So that** they can be provided to the Consumer.

Acceptance criteria

**When** I, the Governance Authority, receive a federated search request from a Trusted Governance Authority\
**And** the Consumer is authorised with the identity attributes for searching\
**Then** Simpl-Open replies to trusted governance authority with the resource descriptions matching the search criteria.
